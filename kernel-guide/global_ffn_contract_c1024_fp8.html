01. Define the model piece before choosing a GPU tile

global_ffn_contract_c1024_fp8 belongs to the C1024 bottleneck, records 31–38. It contracts the activated dense-FFN intermediate U[T,4096] through W₂[4096,1024] and adds the separately scaled original block input X. With row-vector notation the equation is Z[t,n]=Publish(Σₖ U[t,k]W[k,n]+ffn_scale[n]·X[t,n]). The result is logically [T,1024]. The scale has 1024 channel values and broadcasts over tokens. There is no activation or matrix bias in this entry.

The architecture’s 4K example has H=36,W=60,T=2160. This body uses T=BatchCount·TokensPerBatch; the prepared plan runs batch one. Inputs, matrix operands and final output use FP8. Residual scales, accumulators and intermediate split sums use Half. The entry instantiates global_contract_fp8 with bAttentionProjection=false. The architecture document locates this operation in the block, while this lesson derives its implementation locally.

02. Write a scalar baseline and identify the repeated work

This baseline says one output reads all 4096 channels at one token plus one residual value. There is no communication between token t and token t+1. Assigning one thread to each output would reread each input row for many output columns, and reread the same W columns for every token. Separate residual and publication kernels would add further global reads/writes. Those costs suggest grouping outputs, reusing operand panels and fusing the residual. The scalar equation is a dependency reference; exact deployment equivalence additionally requires the recovered split order and Half rounding described below.

One instruction computes a 16-token × 8-output-channel tile with a reduction of 32 channels. All 32 lanes participate in the same matrix operation. Each lane supplies four 32-bit A words, two 32-bit B words, and two 32-bit C words. Each C word contains two Half accumulators, so a lane owns four output elements. A source loop over output groups or reduction panels repeats this operation; it does not launch a new warp.

The exact instruction on this path is mma.sync.aligned.m16n8k32.row.col.f16.e4m3.e4m3.f16. Both the accumulator input and output are Half. Do not replace its numerical contract with FP32 accumulation when constructing an exact oracle. For the FP8 path, packing to E4M3 is a distinct rounding step; for the FP16 path a packed word simply holds two Half values.

Let lane L run from 0 to 31, g = L // 4 and q = L % 4. The matrix coordinates below describe instruction operands after any kernel-specific loads and shuffles. Storage layouts are designed to supply these coordinates cheaply.

The operand and accumulator coordinates follow the NVIDIA PTX matrix-fragment specification. A kernel may permute model channels before supplying these instruction coordinates; its publication and weight-packing rules must agree.

03. Grow a warp primitive into the source CTA

Four M16 fragments and eight N8 fragments give one warp a 64×64 output. Represent it as four M16 groups × four N16 groups × four Half2 accumulator words per lane. Arrange four warps as two token halves and two channel halves to cover M128×N128. This keeps each output fragment in registers while reusing one A fragment across multiple N panels and one B fragment across four M panels. A CTA contains 128 threads, with lane=threadIdx.x and warp=threadIdx.y.

Let Mtiles=ceil(T/128). For block.x=b, channelBlock=floor(b/Mtiles), firstGroup=(b modMtiles)·8 and outputChannel=128·channelBlock+64·(warp mod2). The warp consumes groups firstGroup+4·floor(warp/2)+m, m=0…3. Split selection is OrderedSplit ? OrderedSplit−1 : blockIdx.z. Unlike an ordinary complete GEMM, this CTA computes only 1024 of the 4096 input channels. Four such partial computations contribute to the same output addresses.

Define the packed layout before optimizing memory traffic

The public pointers address opaque packed buffers. A token group contains 16 rows. One native M16×K32 A panel consumes 512 bytes, distributed as 32 lanes ×16 bytes. For input width K and element size E, group g begins at g·16·K·E. A reduction step advances along K in whole panels. Within a panel, lane L reads the vector at L·16. The publication layout arranges token rows and channel pairs to make those four words immediately usable by MMA.

A packed B panel for 16 output channels also occupies 512 bytes. One lane’s uint4 supplies two N8 fragments: the first two words belong to the first N8, the next two words to the second. Across K panels, the record advances by N·32 bytes, where this kernel’s N is 1024. The equality follows from 32 reduction values × 1 bytes per value =32 bytes per output column. A cache-all vector load fetches those words directly to registers.

The FP8 matrix’s natural-channel decoder first applies inverse_packed_input_index(k), then packed_weight_index. This permutation is essential: a native MMA K coordinate and a model channel are different labels. The input producer’s packing and the weight row permutation agree. When building fixtures, use those maps together; blindly writing natural-channel rows into the raw byte record does not create the intended matrix.

04. Introduce four K splits without losing the residual or rounding order

Partition K into ranges [0,1024),[1024,2048),[2048,3072),[3072,4096). Split s computes its own Half MMA result Cₛ. Only s=0 starts its accumulator from HalfMul(scale,residual); later splits start from zero. Adding the residual in all four splits would multiply that path by four. Adding it after all dots instead would change the existing Half accumulation sequence.

After independent computation, publish in order: P₀=C₀; P₁=HalfAdd(P₀,C₁); P₂=HalfAdd(P₁,C₂); final=HalfAdd(P₂,C₃). P is a separate global Half tensor; only final is converted to E4M3 and stored in the FP8 output. Three intermediate E4M3 publications would be numerically wrong. This is not an arbitrary-order atomic sum and not one FP32 reduction. The structure reproduces the recorded publication boundaries.

05. Derive input, weight, residual and partial addresses

Within one split, the reduction advances by K64, giving 16 steps. One 16-token group’s slab contains 64·16·1=1024 bytes. Its global base is U+(g·4096+s·1024+i·64)·16·1. The eight groups together occupy 8192 bytes per shared stage. This specialization copies 1024 bytes per producer operation, so 1 producer warp positions cooperate per group. In the source’s unified copy loop, copySlot=warp+4·Copy, group=firstGroup+floor(copySlot/1), and destination=stage·8192+copySlot·1024. Contraction coalesces the two K fragments in each 1024-byte group slab.

The consumer A vector is at shared (i mod2)·8192+floor(warp/2)·4·1024+lane·16+m·1024+kSubtile·512. W’s register vector starts at W+(s·1024+i·64)·1024·1+outputChannel·32+lane·16+kSubtile·32768+n16·512. There are 2 native K subtiles per step. The fixed 32768 stride is 1024 output columns ×32 bytes per native K panel; it is independent of the scalar element width.

For a Half partial, the address is partial+(g·1024+outputChannel)·32+lane·16+n16·512. The factor 32 is 16 tokens ×2 bytes. A residual vector instead uses the working element width: X+(g·1024+outputChannel)·16·1+lane·16+publicationPanel·512. Scale pairs are always Half, appended at W+4096·1024·1; within that tail, the byte offset is 2·(outputChannel+16·n16+8·n8+2·(lane mod4)). The example’s n16=2,n8=0,lane 13 therefore selects scale channels 34/35, beginning 68 bytes beyond the matrix.

There is no Half-only small-input broadcast condition in this specialization.

06. Build a one-slot synchronous split kernel

At this point the arithmetic, addresses, residual and partial-tensor lifetime are complete. The remaining bottleneck in the scaffold is exposed copy latency between repeated matrix tiles. The source adds 2 shared stages, totaling 16384 data bytes plus 16 barrier bytes. This two-slot specialization begins with one ready stage and peels its final MMA out of the loop. B remains in registers rather than occupying another shared ring.

07. Replace the scaffold with the actual stage schedule

Make the copy barrier part of the construction

Allocate 2 shared data slots and one 8-byte mbarrier per slot. Lane 0 of warp 0 initializes each barrier with 128 expected thread arrivals, then the CTA synchronizes before any producer can issue copies. On SM90+, IsCopyProducer elects one lane per participating warp; it issues an ordinary-address cp.async.bulk and registers the transferred byte count. On SM80/89, every lane issues 16-byte cp.async.cg stripes and attaches its own copies with cp.async.mbarrier.arrive. A 512-byte transfer needs one stripe per lane, a 1024-byte transfer needs two.

ArriveAndWait makes every thread arrive, obtains the current phase token, and polls until that exact phase completes. Reusing the same barrier address next iteration requires a new token; readiness from a previous cycle is insufficient. Completion also accounts for attached asynchronous transfers. Ordinary thread arrival alone cannot establish copy completion. The schedule must separately establish that the previous tile’s readers have finished before a slot is overwritten. No tensor-map descriptor, TMEM allocation, warp-group MMA or shared-to-register ldmatrix operation is used in this path: its shared vectors already have the correct MMA fragment order.

Global storage is backed by device memory; L2 and L1 are hardware-managed caches on relevant load/store paths. The source’s .ca weight loads permit all-level caching. Its pre-SM90 .cg asynchronous copies use the global cache level. L1::no_allocate output stores request no new L1 allocation. None of these hints implies a guaranteed hit rate or replaces synchronization. NVIDIA’s PTX cache specification defines those distinctions.

Below SM90 the body issues A(i+1) before consuming the current tile. The prior stage wait has already carried all threads past the old slot’s consumption, so this early prefetch can overlap current MMA work. On SM90+ it preserves the recovered placement after consumption. In both branches B(i) remains in registers until its MMA finishes; only then does LoadWeights replace it with B(i+1). The loop stops at steps−2, and the last ready tile is consumed once outside it. Reordering waits and refills based only on modulo arithmetic can overwrite a stage before every reader has finished.

08. Publish partials and the final tensor

Split 0 stores its Half partial with no L1 allocation. Splits 1/2 use exclusive .cg load → HalfAdd → no-allocate store on SM<90; vector Half reduction on SM90+. Split 3 loads the accumulated predecessor partial, performs four Half2 adds per N16 tile, then writes E4M3 output bytes by pairing two N16 groups. The portable FP8 scratch load uses .cg to avoid retrieving a prior phase’s stale L1 copy; on SM90+ the helper retains its cache-all load. These choices affect instruction and cache behavior, but do not change the required ownership: one lane in the current split owns each published vector.

Order split publication independently of computation

The source supports two protocols. With OrderedSplit=0, blockIdx.z is the logical split. A later split may compute its matrix partial while its predecessor runs, but before touching the predecessor’s global partial it polls the corresponding counter until the recorded split is available. The counter starts at −1, and each producer performs a release counter store after its publication and a CTA synchronization. The portable FP8 contraction/projection path additionally calls AcquireSplitPublication after successfully polling, then uses a CTA barrier to pass that visibility to the other lanes.

With OrderedSplit=s+1, the host launches only the XY plane for split s, with grid.z=1. The same stream completes that plane before entering the next split. The kernel skips the resident predecessor wait. The launcher selects this path when the complete dependent grid cannot fit its occupancy-derived capacity; otherwise waiting consumers could occupy resources needed by unscheduled producers. It preserves all 4 partials and their Half rounding rather than replacing them with a different reduction.

Keep scratch, output, residual and counter allocations live until their final consumers finish. Registers and shared memory belong to one CTA invocation and cannot carry a result into the next split launch. The partial tensor is the explicit storage bridge. Counters govern publication, not the mathematical value of a matrix element.

For this entry the four-byte counter address is g_SplitCounters+(firstGroup+channelBlock)·4. There are eight 128-channel output blocks; firstGroup=8·tokenTile, so this indexes one counter per token tile/output-channel block. Later resident splits wait until the signed counter is at least s−1. After all lane stores and the CTA synchronization, lane 0/warp 0 releases the current split number s.

09. Complete reconstruction pseudocode

10. Test the properties that define this kernel

  1. Residual once: set W to zero. Valid output rows should equal the documented publication of HalfMul(scale,residual), with no factor of four and no contribution from other tokens.
  2. Each split contributes: place one nonzero input/weight pair in each K region and compare saved P₀,P₁,P₂ and final. They must follow the specified Half addition order. Values chosen near Half rounding boundaries distinguish this from a reassociated or FP32 sum.
  3. Scratch format: inspect the first three partials as Half, not E4M3, and verify no final FP8 vector is considered ready before split 3.
  4. Address ownership: use the worked token 83/channel 34 example and nearby lane/channel groups. Every output vector must be written once per publication phase, and guard bytes must remain unchanged.
  5. Schedule equivalence: run both admitted resident mode and forced ordered split mode on supported hardware; final bytes should agree. Include more XY blocks than fit in one wave to exercise the host’s capacity fallback.
  6. Tail and ring behavior: use legal token extents around group and CTA boundaries; exercise all 16 K steps so the 2 slots wrap repeatedly. Invalid groups must be zero during computation and omitted from output publication.

The optimization argument follows the construction: grouped MMA shares A across columns and B across tokens; the residual seed removes a separate pass; the staged A ring can overlap transfer with work; register B avoids a shared weight copy; split-specific epilogues avoid converting partials too early. Splitting also creates global scratch traffic and synchronization, and extra stages consume shared capacity. Those tradeoffs need measurements for this precision and geometry; this lesson reports no invented speedup.

71					*reinterpret_cast<uint4*>(s_Storage + s_Destination + s_Subtile * 512 +
72											  TileCoordinates.Lane * 16) = make_uint4(0, 0, 0, 0);
73			}
74		}
75	};
76
77	// Only a completed stage can feed the register MMA tile.
78	const auto WaitStage = [&](int ReductionTile)
79	{
80		const int s_Barrier = Profile::s_BarrierOffset + (ReductionTile % Profile::s_StageCount) * 8;
81		ArriveAndWait(s_Storage, s_Barrier);
82	};
83
84	// Initialize the shared copy barriers before any warp issues input transactions.
85	if (Lane == 0 && Warp == 0)
86		#pragma unroll
87		for (int s_Stage = 0; s_Stage < Profile::s_StageCount; ++s_Stage)
88			BarrierInit(s_Storage, Profile::s_BarrierOffset + s_Stage * 8, blockDim.x * blockDim.y);
89	__syncthreads();
90
91	uint4 r_Weights[Profile::ReductionSubtiles][4];
92
93	// Prefetch weights without changing the ring dependency order.
94	const auto LoadWeights = [&](int ReductionTile)
95	{
96		const uint64_t g_WeightTileBase = Parameters.g_PackedWeights +
97										  uint64_t(TileCoordinates.Split * Profile::SplitChannels +
98												   ReductionTile * Profile::ReductionStep) *
99											  1024 * Profile::ElementBytes +
100										  TileCoordinates.g_OutputChannel * 32 + TileCoordinates.Lane * 16;
101		#pragma unroll
102		for (int r_KSubtile = 0; r_KSubtile < Profile::ReductionSubtiles; ++r_KSubtile)
103			#pragma unroll
104			for (int r_ChannelGroup = 0; r_ChannelGroup < 4; ++r_ChannelGroup)
105				r_Weights[r_KSubtile][r_ChannelGroup] = __ldca(reinterpret_cast<const uint4*>(
106					g_WeightTileBase + r_KSubtile * 32768 + r_ChannelGroup * 512));
107	};
108
109	// Prime the weight registers and input pipeline before entering the reduction loop.
110	LoadWeights(0);
111	#pragma unroll
112	for (int s_InitialStage = 0; s_InitialStage < Profile::s_InitialStages; ++s_InitialStage)
113		StageInput(s_InitialStage);
114	WaitStage(0);
115	FGlobalContractAccumulator r_Accumulator{};
116
117	// Only the first K split seeds the accumulator from the residual.
118	if (TileCoordinates.Split == 0)
119	{
120		// The record appends 1024 Half scales to the matrix. Lane's two adjacent
121		// channels share a packed scale; words 0/1 and 2/3 belong to separate N8s.
122		uint32_t r_ResidualScales[4][2];
123		#pragma unroll
124		for (int r_ChannelGroup = 0; r_ChannelGroup < 4; ++r_ChannelGroup)
125			#pragma unroll
126			for (int r_N8 = 0; r_N8 < 2; ++r_N8)
127				r_ResidualScales[r_ChannelGroup][r_N8] = *reinterpret_cast<const uint32_t*>(
128					Parameters.g_PackedWeights + Profile::MatrixBytes +
129					(TileCoordinates.g_OutputChannel + r_ChannelGroup * 16 + r_N8 * 8 +
130					 (TileCoordinates.Lane & 3) * 2) *
131						2);
132
133		#pragma unroll
134		for (int r_Spatial = 0; r_Spatial < 4; ++r_Spatial)
135		{
136			const int g_Group =
137				TileCoordinates.bBroadcastInput
138					? 0
139					: TileCoordinates.g_TokenGroupBase + (TileCoordinates.Warp >> 1) * 4 + r_Spatial;
140			const uint64_t g_ResidualTileBase =
141				Parameters.g_Residual +
142				uint64_t(g_Group * 1024 + TileCoordinates.g_OutputChannel) * 16 * Profile::ElementBytes +
143				TileCoordinates.Lane * 16;
144			{
145				#pragma unroll
146				for (int r_ChannelPair = 0; r_ChannelPair < 2; ++r_ChannelPair)
147				{
148					const uint4 r_PackedResidual =
149						g_Group < TileCoordinates.g_PaddedGroups
150							? __ldcg(reinterpret_cast<const uint4*>(g_ResidualTileBase + r_ChannelPair * 512))
151							: make_uint4(0, 0, 0, 0);
152					const uint32_t r_PackedResidualWords[4] = {r_PackedResidual.x, r_PackedResidual.y,
153															   r_PackedResidual.z, r_PackedResidual.w};
154					#pragma unroll
155					for (int r_InPair = 0; r_InPair < 2; ++r_InPair)
156					{
157						const int r_ChannelGroup = r_ChannelPair * 2 + r_InPair;
158						auto& r_AccumulatorWords =
159							r_Accumulator.r_AccumulatorWords[r_Spatial][r_ChannelGroup];
160						r_AccumulatorWords[0] =
161							HalfMul(DecodeE4(uint16_t(r_PackedResidualWords[r_InPair * 2])),
162									r_ResidualScales[r_ChannelGroup][0]);
163						r_AccumulatorWords[1] =
164							HalfMul(DecodeE4(uint16_t(r_PackedResidualWords[r_InPair * 2 + 1])),
165									r_ResidualScales[r_ChannelGroup][0]);
166						r_AccumulatorWords[2] =
167							HalfMul(DecodeE4(uint16_t(r_PackedResidualWords[r_InPair * 2] >> 16)),
168									r_ResidualScales[r_ChannelGroup][1]);
169						r_AccumulatorWords[3] =
170							HalfMul(DecodeE4(uint16_t(r_PackedResidualWords[r_InPair * 2 + 1] >> 16)),
171									r_ResidualScales[r_ChannelGroup][1]);
172					}
173				}
174			}
175		}
176	}
177
178	// Native two-stage code peels the final MMA tile out of the prefetch loop.
179	// Keeping that drain explicit removes a per-iteration tail branch. The
180	// three-stage Half contraction retains its distinct refill lifecycle.
181	#pragma unroll 1
182	for (int ReductionTile = 0;
183		 ReductionTile < Profile::ReductionTiles - (Profile::s_InitialStages == 1 ? 1 : 0); ++ReductionTile)
184	{
185#if __CUDA_ARCH__ < 900
186		// WaitStage(i) completed every thread's arrival after Consume(i-1),
187		// releasing that old slot. Prefetch i+1 into it while i's MMA runs in
188		// the other slot; the weight registers still hold i until consumption.
189		StageInput(ReductionTile + 1);
190#endif
191		ConsumeGlobalContractInputStage<Profile>(r_Accumulator, r_Weights, s_Storage, ReductionTile,
192												 TileCoordinates);
193		{
194#if __CUDA_ARCH__ >= 900
195			StageInput(ReductionTile + 1);
196#endif
197			LoadWeights(ReductionTile + 1);
198			WaitStage(ReductionTile + 1);
199		}
200	}
201
202	ConsumeGlobalContractInputStage<Profile>(r_Accumulator, r_Weights, s_Storage, Profile::ReductionTiles - 1,
203											 TileCoordinates);
204
205	// Compile-time split policy keeps the native branch outside all store loops.
206	const auto PublishFragments = [&](auto PublicationTag)
207	{
208		constexpr auto Publication = decltype(PublicationTag)::value;
209		const bool bFirstSplit = Publication == EGlobalContractSplitPublication::Runtime
210									 ? TileCoordinates.Split == 0
211									 : Publication == EGlobalContractSplitPublication::First;
212		const bool bIntermediateSplit = Publication == EGlobalContractSplitPublication::Runtime
213											? TileCoordinates.Split < 3
214											: Publication == EGlobalContractSplitPublication::Intermediate;
215
216		// Serial publication preserves the DLL's Half rounding between K splits.
217		// FP8 keeps partial sums in a separate Half buffer until the fourth split.
218		const uint64_t g_PartialSums = bFp8 ? Parameters.g_SplitAccumulator : Parameters.g_Output;
219		#pragma unroll
220		for (int r_Spatial = 0; r_Spatial < 4; ++r_Spatial)
221		{
222			const int g_Group =
223				TileCoordinates.g_TokenGroupBase + (TileCoordinates.Warp >> 1) * 4 + r_Spatial;
224			if (g_Group < TileCoordinates.g_PaddedGroups)
225			{
226				const uint64_t g_HalfBase = g_PartialSums +
227											uint64_t(g_Group * 1024 + TileCoordinates.g_OutputChannel) * 32 +
228											TileCoordinates.Lane * 16;
229				#pragma unroll
230				for (int r_ChannelGroup = 0; r_ChannelGroup < 4; ++r_ChannelGroup)
231				{
232					auto& r_AccumulatorWords = r_Accumulator.r_AccumulatorWords[r_Spatial][r_ChannelGroup];
233					const uint64_t g_PartialSumAddress = g_HalfBase + r_ChannelGroup * 512;
234					if (bFirstSplit)
235						StoreNoAllocate(g_PartialSumAddress,
236										make_uint4(r_AccumulatorWords[0], r_AccumulatorWords[1],
237												   r_AccumulatorWords[2], r_AccumulatorWords[3]));
238					else if (bIntermediateSplit)
239						AccumulateExclusiveHalf4(g_PartialSumAddress,
240												 make_uint4(r_AccumulatorWords[0], r_AccumulatorWords[1],
241															r_AccumulatorWords[2], r_AccumulatorWords[3]));
242					else
243					{
244						const uint4 r_PreviousSplitWords = LoadSplitAccumulatorHalf4(g_PartialSumAddress);
245						r_AccumulatorWords[0] = HalfAdd(r_PreviousSplitWords.x, r_AccumulatorWords[0]);
246						r_AccumulatorWords[1] = HalfAdd(r_PreviousSplitWords.y, r_AccumulatorWords[1]);
247						r_AccumulatorWords[2] = HalfAdd(r_PreviousSplitWords.z, r_AccumulatorWords[2]);
248						r_AccumulatorWords[3] = HalfAdd(r_PreviousSplitWords.w, r_AccumulatorWords[3]);
249						{
250						}
251					}
252				}
253				{
254					const bool bFinalSplit = Publication == EGlobalContractSplitPublication::Runtime
255												 ? TileCoordinates.Split == 3
256												 : Publication == EGlobalContractSplitPublication::Final;
257					if (bFinalSplit)
258					{
259						const uint64_t g_OutputBase =
260							Parameters.g_Output +
261							uint64_t(g_Group * 1024 + TileCoordinates.g_OutputChannel) * 16 +
262							TileCoordinates.Lane * 16;
263						#pragma unroll
264						for (int r_ChannelPair = 0; r_ChannelPair < 2; ++r_ChannelPair)
265						{
266							const auto& r_LowerChannelWords =
267								r_Accumulator.r_AccumulatorWords[r_Spatial][r_ChannelPair * 2];
268							const auto& r_UpperChannelWords =
269								r_Accumulator.r_AccumulatorWords[r_Spatial][r_ChannelPair * 2 + 1];
270							StoreNoAllocate(
271								g_OutputBase + r_ChannelPair * 512,
272								make_uint4(PackHalfPairsE4(r_LowerChannelWords[0], r_LowerChannelWords[2]),
273										   PackHalfPairsE4(r_LowerChannelWords[1], r_LowerChannelWords[3]),
274										   PackHalfPairsE4(r_UpperChannelWords[0], r_UpperChannelWords[2]),
275										   PackHalfPairsE4(r_UpperChannelWords[1], r_UpperChannelWords[3])));
276						}
277					}
278				}
279			}
280		}
281	};
282
283	const uint64_t g_SplitCounters =
284		Parameters.g_SplitCounters + (TileCoordinates.g_TokenGroupBase + TileCoordinates.g_ChannelBlock) * 4;
285
286	// Ordered launches complete their predecessor before entering this kernel,
287	// so they never occupy an SM while polling an unscheduled producer.
288	if (Parameters.OrderedSplit == 0 && TileCoordinates.Split > 0)
289	{
290		if (TileCoordinates.Lane == 0 && TileCoordinates.Warp == 0)
291		{
292			while (int32_t(CounterLoadRelaxed(g_SplitCounters)) < TileCoordinates.Split - 1)
293				PollSleep(64);
294#if __CUDA_ARCH__ < 900
295			// Acquire the completed split before any lane reads its Half scratch.
296			AcquireSplitPublication();
297#endif
298		}
299
300		__syncthreads();
301	}
302
303	{
304		// The native epilogue selects first-store, intermediate-reduction or
305		// final-pack once. Keep that uniform choice outside fragment loops.
306		if (TileCoordinates.Split == 0)
307			PublishFragments(std::integral_constant<EGlobalContractSplitPublication,
308													EGlobalContractSplitPublication::First>{});
309		else if (TileCoordinates.Split < 3)
310			PublishFragments(std::integral_constant<EGlobalContractSplitPublication,
311													EGlobalContractSplitPublication::Intermediate>{});
312		else
313			PublishFragments(std::integral_constant<EGlobalContractSplitPublication,
314													EGlobalContractSplitPublication::Final>{});
315	}
316
317	__syncthreads();
318	if (TileCoordinates.Lane == 0 && TileCoordinates.Warp == 0)
319		CounterStoreRelease(g_SplitCounters, TileCoordinates.Split);
320#else
321	// Keep the exported entry on older targets, but never silently skip FP8 work.
322	__trap();
323#endif
324}
