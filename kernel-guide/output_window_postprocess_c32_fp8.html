01. The whole problem

The decoder supplies a half-resolution 32-channel field and a full-resolution 32-channel skip saved by the frontend. This kernel performs nearest-neighbor expansion, a learned per-channel merge, one fused C32 FFN/attention block, a four-channel image head, and optional temporal display composition. This document covers the FP8 E4M3 public entry from its inputs to its final stores.

Each block owns an 8×8 window, or 64 tokens. Four 4×4 physical tiles supply 16-token matrix fragments. The prepared launcher uses one warp, block=(32,1,1), so the 32 CUDA lanes collectively own each matrix tile. All lanes must participate in shuffles and matrix instructions. Spatial predicates control boundary loads and stores without allowing a lane to exit before collective work. The grid accounts for OriginX/OriginY, which may be 0 or −4. The physical image dimensions are multiples of eight; the valid renderer extent can be smaller.

The architecture's transformer sub-block is 32→128→32 FFN, followed by one 32-channel attention head over the 64-token window. Its optimized numerical operations include explicit Half rounding and a recovered attention-weight approximation. We will define them locally below. The final learned head uses Half matrix multiplication even in this FP8 entry. The architecture companion provides the broader encoder–decoder map.

Build a scalar oracle for one window

Separate correctness from layout initially. Represent a window as [64,channels], implement the feature or merge operation, then the linear maps, activation, Q/K normalization, attention weights, weighted values and residuals. Preserve every publication boundary and Half arithmetic order. Once that oracle agrees for one window, replace one stage at a time with the packed implementation. A standard library FFN or softmax is useful as a conceptual sketch but cannot be the final bit-level oracle for these recovered formulas.

Here publish means round and pack Half results into E4M3 operand bytes. It does not necessarily mean a global-memory write. The raw adapter/merge and raw FFN residual remain available as Half register fragments even when a published copy is consumed by the next matrix instruction.

02. One CTA: its concrete subproblem

This entry assigns a complete 8 × 8 window to one 32-thread CTA. For an unshifted 16 × 16 field, a 2 × 2 grid covers four disjoint windows. CTA (0,0) owns 64 tokens including our traced pixel (5,1). Its internal 32-channel block evaluates four 16-token matrix tiles, a 32 → 128 → 32 FFN, and one 64 × 64 local-attention table. That table is distributed across register fragments; it is not a global allocation.

The merge reads a 4 × 4 low patch plus a full 8 × 8 skip. The image head consumes 64 × 32 raw Half features and produces four useful values per pixel; the formatted surface receives 64 float4 pixels, or 1024 logical bytes for an entirely valid window.

The output origin can be 0 or −4. Low and skip gathers predicate their own extents; final pixels outside the physical output are skipped only after the matrix/shuffle work. Renderer-valid bounds separately control color/history composition. The measured launch panel gives the actual profiled frame geometry; the small field here is an explicit address example.

03. Warp and thread ownership

One warp owns all four 4 × 4 tiles and every channel of the C32 transformer. Ownership changes inside the warp: low-plane and skip fragments first follow MMA ownership, then the small image head is transposed into one pixel per image lane. For token 13 at (5,1), tile1,row5, the transformer output pair c20/c21 lives in lane22,column2,rowHalf0. Lane22 also owns a different token in rowHalf1; every shuffle must select the correct row half.

Define storage and the 16-token instruction

A global allocation is device memory addressed by a pointer; loads can be served by hardware-managed L2 and, depending on the instruction, L1. A cache hit is not another program-visible tensor and the source does not guarantee cache residency. __ldca permits caching at all levels; __ldcg and PTX .cg select global-level caching that bypasses L1. An eviction or no_allocate hint is a performance policy, not a publication barrier.

Shared memory is an explicitly indexed block-local allocation. Another warp may read a producer's values only after the required block barrier or completed asynchronous-copy protocol. A warp shuffle exchanges register values among its active lanes; it does not address shared memory. Arrays named r_… express per-thread values, but only compiler output establishes whether they stay in physical registers or spill to local memory. Tensor-core accumulator fragments are also register operands. These kernels use mma.sync, not TMEM.

One instruction computes a 16-token × 8-output-channel tile with a reduction of 32 channels. All 32 lanes participate in the same matrix operation. Each lane supplies four 32-bit A words, two 32-bit B words, and two 32-bit C words. Each C word contains two Half accumulators, so a lane owns four output elements. A source loop over output groups or reduction panels repeats this operation; it does not launch a new warp.

The exact instruction on this path is mma.sync.aligned.m16n8k32.row.col.f16.e4m3.e4m3.f16. Both the accumulator input and output are Half. Do not replace its numerical contract with FP32 accumulation when constructing an exact oracle. For the FP8 path, packing to E4M3 is a distinct rounding step; for the FP16 path a packed word simply holds two Half values.

05. Execution and scheduling

This flowchart follows source dependencies through the entire launch. The low expansion, residual merge, transformer, head and final composition communicate in registers and through warp instructions; this entry declares no shared tensor. All 32 lanes participate in the MMA and shuffle steps. A warp scheduler can interleave this CTA with others, but the source establishes no asynchronous-copy pipeline or cross-CTA handshake.

The principal lifetime decisions are deliberate: keep the raw Half merge for the FFN residual; stream one of four hidden panels at a time; retain the raw FFN result for the attention residual; publish only matrix operands; apply the Half image head as each projected token tile becomes available, then retain only its small result until composition. These dependencies explain the fusion; the resource evidence determines its measured cost.

06. Trace one token through the source

Fix an interior, unshifted window at origin (0,0), with an 8×8 field for the byte examples. Follow natural token 13, pixel (5,1), through tile 1 and physical token 21. Its tile row is 5. For C32 panel zero, accumulator lane 22 owns channels 20/21 in r_Pair[2][0]. Other channels of this token are distributed across lanes 20–23; matrix products mix channels, and attention then mixes token values. Following a token means following this output row and its dependencies, not preserving one scalar unchanged.

Whenever this token is in the native published A layout, channel 20 is in word 2, low E4M3 byte; native K24 corresponds to model channel 20. For an ordinary packed allocation, its containing uint32 starts at tileBytes + 360 = 872 bytes. The allocation base is excluded. View inputs, low planes, feature planes and surfaces use their own equations below; this packed offset must not be applied to those storage layouts.

The transformer keeps this path in thread registers. It has no shared-memory swizzle. The feature-plane gather in an input frontend is a separate, real shared layout and is derived below.

Token checkpoint — merge. For destination accumulator lane22,tile1,rowHalf0, the repeat shuffle selects source lane10, corresponding to low pixel(2,0). The skip contributes at high pixel(5,1). The rounded low product becomes the addend of the Half FMA with scaled skip; the resulting raw pair is retained while a separate published copy feeds the FFN.

Load the low field, expand pixels, and merge the skip

The low field is channel-plane storage at lowH=Height/2, lowW=Width/2. An 8×8 output window starts at ox=8×block.x+OriginX, oy=8×block.y+OriginY. Lane L loads x=ox/2+(L//4)%4 and y=oy/2+L//16+2r for rows r=0,1. Plane p is at byte offset 16×((p×lowH+y)×lowW+x)+4(L%4). Invalid coordinates load zero; a singleton dimension uses coordinate zero for its broadcast case.

This path has two planes, each storing 16 E4M3 channels per pixel. A uint32 load holds four E4 bytes; decode its lower and upper 16-bit halves into two Half pairs. The four resulting Half channel-pair groups share the same later merge schedule. The full-resolution skip uses the native 4×4 tile layout, loaded as uint4 vectors at tileLinear×512+chunk×512+L×16. Decode its packed E4 pairs before the Half merge.

To expand a low pixel into its 2×2 high-resolution cell without materializing an upsampled image, shuffle from lane (L&3) | ((L>>1)&4) | ((tile&1)×8) | (rowHalf×16). Select low-row index tile//2. The lane bit pattern combines unchanged channel ownership with half-resolution pixel ownership. For lane 13, tile 0, rowHalf 0, the source is lane 5; rowHalf 1 uses lane 21. For tile 1 the corresponding lanes are 13 and 29.

The merge is HalfFma(skip,adapterScale,HalfMul(low,inputScale)). First round the low product to Half, then fuse the skip product with its addition. Computing two independently rounded products, fusing the low side instead, or using FP32 for the sum changes the numerical contract. Keep the resulting raw Half merge for the FFN residual, while the matrix-input copy is published to the selected precision.

The E4M3 publication introduces a crucial distinction between a native MMA K coordinate and a model channel. Word 0 packs accumulator column groups 0 and 1 together. Write the surface and close the storage lifetime

NativeSurface2d writes four float bit patterns to the CUDA surface at the selected pixel. The helper passes x unchanged to sust.p.2d.v4.b32.zero. Its .p form uses a surface-sample coordinate, so x selects a float4 pixel directly; there is no explicit multiplication by 16. The helper parameter name ByteCoordinateX and its nearby byte-offset comment are misleading for this formatted instruction. The PTX surface-store specification distinguishes this sample addressing from the byte addressing of sust.b. The surface is backed by a CUDA array, not the low-field or skip pointer. The host copies initial output contents into that array before launch and copies it back afterward, preserving pixels untouched by the configured window origin and bounds.

No explicit shared-memory allocation is required by this output entry: native inputs are gathered through global loads and warp shuffles, and the transformer/head fragments remain thread-local. Reconstruct the output kernel in stages

  1. Implement a scalar nearest-neighbor expansion and exact rounded merge. Verify low-plane and skip-tile loads independently with coordinate/channel-coded values.
  2. Derive the expansion shuffle lane equation and compare each Half pair against the scalar merge before enabling the fused block.
  3. Implement the complete local FFN/attention sequence above with the output-specific record offsets.
  4. Apply the Half head to one raw output tile, then implement the four-shuffle transpose into per-pixel head values.
  5. Add composition one branch at a time: current-color residual, display conversion, exceptional blend scalar handling, history reconstruction, gate, and surface store.

The useful optimizations follow the data lifetimes: upsample in registers, retain raw Half residuals, avoid materializing head and score tensors, reuse loaded weights across four tile fragments, and apply the small head before advancing to the next attention tile. 206		constexpr int CONST_QUERY_TILE_BATCH = bFp8 ? 2 : 1;
207		#pragma unroll
208		for (int r_FirstTile = 0; r_FirstTile < 4; r_FirstTile += CONST_QUERY_TILE_BATCH)
209		{
210			FWindowAccumulatorTile<64> r_Probabilities[CONST_QUERY_TILE_BATCH];
211			#pragma unroll
212			for (int r_LocalTile = 0; r_LocalTile < CONST_QUERY_TILE_BATCH; ++r_LocalTile)
213				r_Probabilities[r_LocalTile] = QueryKeyScores<bFp8>(
214					r_FirstTile + r_LocalTile, g_PackedWeights + FConfig::BiasOffset, r_Query, r_Key);
215			SoftmaxWindowPair(r_Probabilities);
216
217			#pragma unroll
218			for (int r_LocalTile = 0; r_LocalTile < CONST_QUERY_TILE_BATCH; ++r_LocalTile)
219			{
220				const int r_Tile = r_FirstTile + r_LocalTile;
221				const auto r_Attended = ProbabilityValues<bFp8>(r_Probabilities[r_LocalTile], r_Value);
222				#pragma unroll
223				for (int r_Column = 0; r_Column < 4; ++r_Column)
224					#pragma unroll
225					for (int r_RowHalf = 0; r_RowHalf < 2; ++r_RowHalf)
226						r_Ffn[r_Tile].r_Pair[r_Column][r_RowHalf] =
227							HalfMul(r_Ffn[r_Tile].r_Pair[r_Column][r_RowHalf], r_AttentionScale[r_Column]);
228				LinearWindow32(PublishWindow32<bFp8>(r_Attended), r_OutputWeights, r_Ffn[r_Tile]);
229
230				// Apply the output head here before advancing the attention tile.
231				{
232					uint32_t r_HeadAccumulator[2] = {0, 0};
233					#pragma unroll
234					for (int r_ReductionChunk = 0; r_ReductionChunk < 2; ++r_ReductionChunk)
235					{
236						const uint4 r_Weights = __ldca(reinterpret_cast<const uint4*>(
237							WindowParameters.g_PackedWeights +
238							FPostprocessWindowProfile<bFp8>::CONST_HEAD_OFFSET + r_ReductionChunk * 512 +
239							threadIdx.x * 16));
240						const uint32_t r_HeadWeightFragment[2] = {r_Weights.x, r_Weights.y};
241						MmaWindowFragment<false>(PublishWindowChunk<false>(r_Ffn[r_Tile], r_ReductionChunk),
242												 r_HeadWeightFragment, r_HeadAccumulator);
243					}
244					WindowParameters.r_Head[r_Tile][0] = r_HeadAccumulator[0];
245					WindowParameters.r_Head[r_Tile][1] = r_HeadAccumulator[1];
246				}
247			}
248		}
249	}
250
251	// Decode the learned head, blend renderer inputs, and write valid output pixels to the surface.
252	#pragma unroll
253	for (int r_TileRow = 0; r_TileRow < 2; ++r_TileRow)
254	{
255		// Gather the four Half head channels into one RGBA pixel per lane.
256		const int Lane = threadIdx.x;
257		const int r_LocalRowHalf = Lane & 1, r_LocalTile = (Lane >> 1) & 1;
258		const int r_SourceLane = ((Lane & 7) << 2) | (Lane >> 3);
259		const uint32_t r_GatheredHeadWords[4] = {
260			ShuffleIdx(r_Head[r_TileRow * 2 + r_LocalTile][r_LocalRowHalf], r_SourceLane, CONST_WARP_CLAMP,
261					   CONST_WARP_MEMBERS),
262			ShuffleIdx(r_Head[r_TileRow * 2 + r_LocalTile][1 - r_LocalRowHalf], r_SourceLane ^ 1,
263					   CONST_WARP_CLAMP, CONST_WARP_MEMBERS),
264			ShuffleIdx(r_Head[r_TileRow * 2 + 1 - r_LocalTile][r_LocalRowHalf], r_SourceLane ^ 2,
265					   CONST_WARP_CLAMP, CONST_WARP_MEMBERS),
266			ShuffleIdx(r_Head[r_TileRow * 2 + 1 - r_LocalTile][1 - r_LocalRowHalf], r_SourceLane ^ 3,
267					   CONST_WARP_CLAMP, CONST_WARP_MEMBERS)};
268		const int r_PixelWordIndex = ((Lane >> 3) & 1) | ((Lane >> 3) & 2);
269		const uint2 r_Pixel =
270			make_uint2(r_GatheredHeadWords[r_PixelWordIndex], r_GatheredHeadWords[r_PixelWordIndex ^ 1]);
271		const int g_X =
272			int(blockIdx.x) * 8 + WindowParameters.OriginX + (threadIdx.x / 16) * 4 + (threadIdx.x & 3);
273		const int g_Y =
274			int(blockIdx.y) * 8 + WindowParameters.OriginY + (threadIdx.x % 16) / 4 + r_TileRow * 4;
275
276		// Color conversion, optional temporal blending and final surface publication stay together.
277		if (g_X < 0 || g_Y < 0 || g_X >= Parameters.Width || g_Y >= Parameters.Height)
278			continue;
279		const float Width = __int2float_rn(Parameters.ValidWidth);
280		const float Height = __int2float_rn(Parameters.ValidHeight);
281		const float2 Uv =
282			make_float2(NativeFloatDivide(NativeFloatAdd(__uint2float_rn(g_X), CONST_PIXEL_CENTER), Width),
283						NativeFloatDivide(NativeFloatAdd(__uint2float_rn(g_Y), CONST_PIXEL_CENTER), Height));
284		const float r_HeadChannels[4] = {__half2float(__ushort_as_half(uint16_t(r_Pixel.x))),
285										 __half2float(__ushort_as_half(uint16_t(r_Pixel.x >> 16))),
286										 __half2float(__ushort_as_half(uint16_t(r_Pixel.y))),
287										 __half2float(__ushort_as_half(uint16_t(r_Pixel.y >> 16)))};
288		const bool bValidPixel = g_X < Parameters.ValidWidth && g_Y < Parameters.ValidHeight;
289		float4 r_Color;
290		if (Parameters.ColorTexture && bValidPixel)
291		{
292			const float2 ColorUv = TransformTextureCoordinates(Parameters.ColorTransform, Uv.x, Uv.y);
293			const float4 r_CurrentColor = SampleTexture(Parameters.ColorTexture, ColorUv.x, ColorUv.y);
294			#pragma unroll
295			for (int r_Channel = 0; r_Channel < 3; ++r_Channel)
296				(&r_Color.x)[r_Channel] =
297					NativeFloatFma(Parameters.OutputScale, r_HeadChannels[r_Channel],
298								   NativeFloatFma((&r_CurrentColor.x)[r_Channel], CONST_COLOR_RESIDUAL_SCALE,
299												  CONST_COLOR_RESIDUAL_BIAS));
300		}
301		else
302		{
303			#pragma unroll
304			for (int r_Channel = 0; r_Channel < 3; ++r_Channel)
305				(&r_Color.x)[r_Channel] =
306					NativeFloatMultiply(Parameters.OutputScale, r_HeadChannels[r_Channel]);
307		}
308
309		r_Color.w = CONST_ZERO;
310		if (Parameters.bDisplayOutput)
311		{
312			#pragma unroll
313			for (int r_Channel = 0; r_Channel < 3; ++r_Channel)
314				(&r_Color.x)[r_Channel] = ClampUnit(NativeFloatFma(
315					(&r_Color.x)[r_Channel], CONST_COLOR_DISPLAY_SCALE, CONST_COLOR_DISPLAY_BIAS));
316			r_Color.w = CONST_UNIT;
317		}
318
319		float r_BlendScale = CONST_UNIT;
320		if (Parameters.g_BlendScale)
321		{
322			const float r_LoadedScale =
323				__half2float(__ushort_as_half(*reinterpret_cast<const uint16_t*>(Parameters.g_BlendScale)));
324			const uint32_t r_BlendScaleAbsBits = NativeAbsFtzF32(__float_as_uint(r_LoadedScale));
325			r_BlendScale = NativeSetpEquFtzF32(r_BlendScaleAbsBits, CONST_FP32_INFINITY_BITS)
326							   ? CONST_ZERO
327							   : ClampUnit(r_LoadedScale);
328		}
329
330		if (Parameters.bDisplayOutput && Parameters.HistoryTexture && Parameters.MotionTexture &&
331			bValidPixel && r_BlendScale > CONST_ZERO)
332		{
333			const float2 MotionUv = TransformTextureCoordinates(Parameters.MotionTransform, Uv.x, Uv.y);
334			const float4 r_Motion = SampleTexture(Parameters.MotionTexture, MotionUv.x, MotionUv.y);
335			const float2 PreviousUv =
336				Parameters.bApplyMotion
337					? make_float2(NativeFloatFma(Parameters.MotionScaleX, r_Motion.x, Uv.x),
338								  NativeFloatFma(Parameters.MotionScaleY, r_Motion.y, Uv.y))
339					: Uv;
340			const float3 r_History = ReconstructHistory(
341				Parameters.HistoryTexture, Parameters.HistoryTransform, PreviousUv, Width, Height);
342			const float r_GateExponential = __uint_as_float(NativeEx2ApproxFtzF32(__float_as_uint(
343				NativeFloatMultiply(r_HeadChannels[3], __uint_as_float(CONST_NEGATIVE_LOG2_E_BITS)))));
344			const float r_HistoryBlendWeight = ClampUnit(NativeFloatMultiply(
345				NativeFloatReciprocal(NativeFloatAdd(r_GateExponential, CONST_UNIT)), r_BlendScale));
346			#pragma unroll
347			for (int r_Channel = 0; r_Channel < 3; ++r_Channel)
348				(&r_Color.x)[r_Channel] =
349					NativeFloatFma(r_HistoryBlendWeight,
350								   NativeFloatSubtract((&r_History.x)[r_Channel], (&r_Color.x)[r_Channel]),
351								   (&r_Color.x)[r_Channel]);
352		}
353
354		NativeSurface2d(Parameters.OutputSurface, g_X, g_Y,
355						make_uint4(__float_as_uint(r_Color.x), __float_as_uint(r_Color.y),
356								   __float_as_uint(r_Color.z), __float_as_uint(r_Color.w)));
357	}
358#else
359	// Keep the exported entry on older targets, but never silently skip FP8 work.
360	__trap();
361#endif
362}
