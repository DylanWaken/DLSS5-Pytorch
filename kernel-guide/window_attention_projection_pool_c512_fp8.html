01. The precise model suboperation: attention output projection

window_attention_projection_pool_c512_fp8 consumes the attended head tensor A, logically [H,W,512], applies a dense [512,512] channel matrix, and combines a separate learned 512-channel residual scale with the published FFN output Z. Its role is record 30, which saves the high-resolution skip and sends a pooled tensor toward C1024. At the documented 4K input the C512 field is [68,120,512]. Every output position mixes channels from the same position; the projection itself does not read spatial neighbors. The pooling suffix adds a spatial 2×2 reduction after that projection.

The network architecture guide, rendered from docs/ARCHITECTURE.md, places this operation in the full encoder–bottleneck–decoder. This lesson defines the operation and its physical implementation locally so it can be read independently.

Write its graph as Yraw[p,n] = Σk Input[p,k]·W[k,n] + scale[n]·R[p,n], then publish Y in E4M3. R is specifically the published FFN output Z, not the projection input. Also compute Pool[y,x,n] = publish(average2x2(Yraw)[y,x,n]); save published Y for decoder record 39. The formula describes connectivity. The implementation seeds its accumulator with the rounded scaled residual before accumulating K, which defines a more specific numerical sequence than evaluating the sum and adding a residual afterward.

02. Start from a scalar projection plus its exact residual branch

A straightforward first kernel assigns one (pixel,output-channel) pair to a thread, loads 512 inputs and weights, forms a dot product, scales the residual and writes the result. This is an easy correctness baseline but repeats input loads for every output and exposes little reuse. A second baseline kernel could then read a high output and pool it. That is numerically wrong for E4 if it pools the published bytes instead of preserving Yraw; a correct unfused baseline must preserve the raw Half result separately. The reconstruction will remove those extra passes by putting the scaled residual into C before matrix multiplication.

The working storage format on this page is E4M3 FP8. Tensor-core accumulation, residual products, the recovered activation and the reduction trees discussed here use packed Half words. A uint32_t is a bit container for two Half values, not an integer approximation to their sum. HalfMul, HalfAdd and HalfFma preserve the source’s separately rounded operations; replacing them with FP32 expressions and a final cast changes that contract. E4 publication calls PackHalfPairsE4 on two Half2 words and produces four bytes. DecodeE4 performs the reverse operand preparation when a residual must participate in Half arithmetic. There is no scale tensor passed to those conversions.

Start with a high-precision scalar oracle to validate which input contributes to which output. Once the connectivity is correct, introduce a second oracle that follows the source’s K chunk order and publication points. A scalar FP32 sum is not a bitwise reference for Half MMA; it is a tool for catching transposes, wrong groups and wrong spatial coordinates. Keep these two correctness goals separate throughout reconstruction.

03. Give each warp a rectangular matrix result

One CTA owns an 8 × 8 position region and 256 output channels. Let columns=ceil(W/8). The spatial X tile is 2·(blockIdx.x%columns), while blockIdx.x/columns selects the 256-channel slab. Warp channel base is 256·slab+64·(warp%4). There are two channel slabs to cover all 512 outputs. Four warps each own 64 channels over all four M16 spatial fragments. This full-window ownership is useful here because each warp must pool its four projected spatial tiles. The public block shape is (32,4); do not choose a different warp count while retaining these coordinate formulas.

One instruction computes a 16-token × 8-output-channel tile with a reduction of 32 channels. All 32 lanes participate in the same matrix operation. Each lane supplies four 32-bit A words, two 32-bit B words, and two 32-bit C words. Each C word contains two Half accumulators, so a lane owns four output elements. A source loop over output groups or reduction panels repeats this operation; it does not launch a new warp.

The exact instruction on this path is mma.sync.aligned.m16n8k32.row.col.f16.e4m3.e4m3.f16. Both the accumulator input and output are Half. Do not replace its numerical contract with FP32 accumulation when constructing an exact oracle. For the FP8 path, packing to E4M3 is a distinct rounding step; for the FP16 path a packed word simply holds two Half values.

Let lane L run from 0 to 31, g = L // 4 and q = L % 4. The matrix coordinates below describe instruction operands after any kernel-specific loads and shuffles. Storage layouts are designed to supply these coordinates cheaply.

04. Derive byte addresses before writing the fast loop

A native input tile represents sixteen positions in a physical 4 × 4 image patch. Its byte extent is 16·512·1 = 8,192. Tile index q advances by that whole extent, an instruction-K stripe advances by 512 bytes, and lane l selects 16·l bytes within the stripe. Thus one A load is input + q·8192 + stripe·512 + lane·16. For q=7, stripe=1 and lane=13, the base-relative address is 58,064 bytes. The lane reads one uint4 containing sixteen E4 values. These values are already arranged as a matrix operand; they are not simply consecutive channels of one pixel.

The weight record groups output columns into N16 panels and reduction channels into K32 instruction slices. Each instruction slice consumes 32·1=32 bytes per output column. Its lane-vector address is W + reductionStart·512·1 + outputChannel·32 + lane·16 + panel·512. For reductionStart=32, outputChannel=128, panel=1 and lane=13, this is 21,200 bytes. The panel term is relative to the warp’s output base. Adding a complete K slice advances 16,384 bytes, not 512: 512 advances N16, while 16,384 advances all 512 output columns.

Write a small host-side address decoder first. Give each logical input element a distinguishable value, encode a single native tile, and check exactly which token/channel arrives in each lane word. Repeat for one weight panel. This isolates layout errors from arithmetic errors: a wrong transpose can still produce plausible values for uniform inputs. In the kernel, all these pointer expressions use byte offsets because the public ABI passes integer addresses rather than typed multidimensional tensor views.

05. Place the residual in accumulator order before the reduction

The packed record holds 512·512·1 = 262,144 matrix bytes, followed by 512 Half scale values, another 1,024 bytes. For an output channel c, the scale address is W+262144+2c. Four lanes cooperate on an N8 row; each lane reads the two scale values corresponding to its channel pair, then uses the same pair for both row halves. Scales remain Half even when the large matrix uses E4. This small but essential mixed-precision field makes “every byte in an FP8 weight record is FP8” an incorrect assumption.

06. Overlap input movement without reusing live bytes

The scalar baseline reloads input independently for each output. Our tiled version first shares an input stripe among output-panel computations. A synchronous prototype can copy a stage, execute a CTA barrier, consume every fragment, then execute a second barrier before overwriting the stage. That establishes correct producer/consumer ownership. The deployed kernel replaces the idle copy phase with a 2-slot ring. A slot holds 4,096 data bytes; its 8-byte barrier lives after all data slots, so the allocation is 2·(4096+8) = 8,208 bytes.

CopyBulk accepts a shared byte offset, a global address, byte count and barrier offset. On SM90+ it uses a bulk asynchronous copy with transaction-byte completion and an elected producer; BarrierExpect registers the expected bytes. On supported earlier targets the helper distributes 16-byte copies across warp lanes and attaches their completion to the mbarrier. BarrierExpect is then intentionally a no-op because that path does not use the transaction-byte mechanism. Initialize every stage barrier once with the full CTA arrival count, then synchronize before any copy can refer to it. An out-of-domain stripe is filled with zeros by its lane writers; those threads still join the barrier protocol.

The prologue loads W0, issues the first 2 input stages and waits for stage zero. Iteration t reads slot t%2, performs its MMA work, loads the next weights and waits for the next stage. Only then does it issue t+2 into the old slot. The intervening full-CTA arrival/wait establishes that all warps have finished the previous read phase before anyone recycles its storage. Preserve this order even if a local warp has already consumed its own fragment.

The 8 outer iterations stay rolled in the source, while spatial, N-panel and instruction-K fragment loops unroll. That lets fixed array indices select register values without expanding the entire long reduction into a huge instruction stream. More stages can hide more copy latency but consume shared memory; more fragments improve operand reuse but increase live registers. Those are the relevant tradeoffs, not a claim that a larger ring is always faster. __maxnreg__ supplies a compiler limit, not an observed register count. Inspect generated resource reports and time representative shapes before changing either knob.

Notice what does not enter shared memory: the weight fragments and the residual accumulator. Weights are fetched as lane vectors and reused across the warp’s spatial fragments. The input stage is shared because several output-group warps need those same bytes. This asymmetry is the optimization: stage the operand with cross-warp reuse, keep independent output ownership in registers, and choose weight cache policy without inventing a second staging ring. It also explains why doubling shared memory for weights is not an automatically beneficial change.

07. Retain raw output for a second consumer: 2 × 2 pooling

The first output is the published high-resolution C512 skip. The second is a native tiled pooled C512 tensor. The kernel keeps the four raw projected spatial tiles in registers while writing the skip, then constructs one pooled 4 × 4 tile. In the 4K geometry [68,120] halves to [34,60], and the next-level field pads this to [36,60]. Bound checks and zero-filled synthetic input tiles create the padded rows; do not average already-published skip bytes to recreate them.

PoolHorizontalWords first routes the left/right tile and row-half words by lane bits, swaps lane bits 2 and 3, then gathers four neighbor words through source-lane XOR 0,4,16,20. It performs exactly three Half additions and a Half quarter multiply, ordered as (TL+TR)+(BL+BR). This helper exchanges values within the warp, not through a shared pooled image. Only after that Half average does this entry convert to E4, so raw-pool fusion preserves a numerical boundary as well as removing traffic.

08. The helper contracts needed to reconstruct this entry

FMmaAccumulatorTile<M,N> contains [M][N][4] 32-bit words per lane. Each N index means sixteen output channels, built from two N8 MMA instructions; it does not mean a sixteen-byte vector in logical row-major order. AccumulateTile takes an array of four-word A fragments and four-word weight bundles, uses the lower two B words for the first N8 result and upper two for the second, and updates the four Half2 words in place. When two instruction-K subtiles exist, it advances each accumulator through subtile zero before subtile one; the FP16 QKV stage supplies only one K16 subtile. The API’s by-value operands ensure an output update does not change the fragment arguments still being evaluated.

StoreNoAllocate emits an aligned 128-bit global store with an L1 no-allocation request. __ldca loads weights with cache-all policy; residual readers may use __ldcg. These are memory-policy choices rather than barriers or promises that an access reaches a particular cache level. A correct implementation must separately satisfy the synchronization protocol and vector alignment. PackHalfPairsE4 changes both element width and which channel pairs occupy the low and high halves of a word. Its order is part of the layout; substituting any four E4 conversions without matching that order is incorrect.

09. Final reconstruction, preserving every lifetime

10. Reconstruction checks, in the order they isolate errors

  1. Use zero W and distinguishable R/scale channels: the output must be the correctly published scaled published FFN output Z, not a scaled copy of the projection input.
  2. Use identity W with zero residual scales to prove the 512-channel projection and byte layout independently. Then test a non-diagonal permutation to detect K/N transposes.
  3. Use one nonzero lane-owned channel at a time, including both N8 halves and both row halves; validate the numeric address example and both 256-channel slabs.
  4. Use an asymmetric 2×2 patch such as 1,2,3,8 to check neighborhood routing, then adversarial Half values to check the exact averaging tree; verify the [34,60] valid region and padded [36,60] field.
  5. Check residual seeding with near-rounding-boundary values; adding the residual after the dot product is not a valid bitwise substitute.
  6. Vary CTA scheduling and run a synchronization checker after any change to stage recycling. Confirm the final iteration neither waits on nor loads a nonexistent K panel.

These are concrete tests to implement when rebuilding the kernel, not claims that this documentation run executed GPU comparisons. First establish layout and numerical equivalence; then measure latency with the same weights, geometry, precision and stream behavior. A source-level eliminated allocation establishes avoided traffic, but it does not quantify the speedup or prove absence of register spills.

A global allocation is device memory addressed by a pointer; loads can be served by hardware-managed L2 and, depending on the instruction, L1. A cache hit is not another program-visible tensor and the source does not guarantee cache residency. __ldca permits caching at all levels; __ldcg and PTX .cg select global-level caching that bypasses L1. An eviction or no_allocate hint is a performance policy, not a publication barrier.

Shared memory is an explicitly indexed block-local allocation. Another warp may read a producer's values only after the required block barrier or completed asynchronous-copy protocol. A warp shuffle exchanges register values among its active lanes; it does not address shared memory. Arrays named r_… express per-thread values, but only compiler output establishes whether they stay in physical registers or spill to local memory. Tensor-core accumulator fragments are also register operands. These kernels use mma.sync, not TMEM.

69	const auto IssueInput = [&](int ReductionTile)
70	{
71		const int s_StageOffset = (ReductionTile % StageCount) * 4096;
72		const int s_BarrierOffset = StageCount * 4096 + (ReductionTile % StageCount) * 8;
73		const int KSubtileIndex = TileCoordinates.Warp & 1;
74		const int g_LocalX = (TileCoordinates.Warp >> 1) & 1;
75
76		// Every stage transfers eight 512-byte stripes across four spatial tiles.
77		// The three-stage ring overlaps input transfers with the register-resident GEMM.
78		#pragma unroll
79		for (int g_LocalY = TileCoordinates.Warp / 4; g_LocalY < TileCoordinates.Warp / 4 + SpatialTiles / 2;
80			 ++g_LocalY)
81		{
82			int g_Y = TileCoordinates.g_TileY + g_LocalY;
83			int g_X = TileCoordinates.g_TileX + g_LocalX;
84			const bool bValid = ResolveSpatialProjectionInputTile(g_Y, g_X, TileCoordinates);
85			const int s_CopyOffset = s_StageOffset + g_LocalY * 2048 + g_LocalX * 1024 + KSubtileIndex * 512;
86			if (bValid)
87			{
88				const uint64_t g_Source = Arguments.g_Input +
89										  uint64_t(g_Y * TileCoordinates.g_TilesWide + g_X + blockIdx.z) *
90											  Profile::SpatialTileBytes +
91										  (ReductionTile * 2 + KSubtileIndex) * 512;
92				if (IsCopyProducer(0xffffffffu))
93				{
94					CopyBulk(s_Storage, s_CopyOffset, g_Source, 512, s_BarrierOffset);
95					BarrierExpect(s_Storage, s_BarrierOffset, 512);
96				}
97			}
98			else
99			{
100				*reinterpret_cast<uint4*>(s_Storage + s_CopyOffset + TileCoordinates.Lane * 16) =
101					make_uint4(0, 0, 0, 0);
102			}
103		}
104	};
105
106	// Wait for the selected shared-memory stage before its fragments are consumed.
107	const auto WaitInput = [&](int ReductionTile)
108	{
109		const int s_BarrierOffset = StageCount * 4096 + (ReductionTile % StageCount) * 8;
110		ArriveAndWait(s_Storage, s_BarrierOffset);
111	};
112
113	// Prime the weight registers and input pipeline before entering the reduction loop.
114	LoadWeights(0);
115	#pragma unroll
116	for (int StageIndex = 0; StageIndex < StageCount; ++StageIndex)
117		IssueInput(StageIndex);
118	WaitInput(0);
119	FSpatialProjectionAccumulator<SpatialTiles> r_Accumulator;
120
121	// Seed the GEMM with the scaled residual in accumulator order.
122	uint32_t r_ResidualScales[4][2];
123	#pragma unroll
124	for (int r_ChannelGroup = 0; r_ChannelGroup < 4; ++r_ChannelGroup)
125		#pragma unroll
126		for (int r_N8 = 0; r_N8 < 2; ++r_N8)
127			r_ResidualScales[r_ChannelGroup][r_N8] =
128				*reinterpret_cast<const uint32_t*>(Arguments.g_PackedWeights + Profile::MatrixBytes +
129												   (TileCoordinates.g_OutputChannel + r_ChannelGroup * 16 +
130													r_N8 * 8 + (TileCoordinates.Lane & 3) * 2) *
131													   2);
132
133	#pragma unroll
134	for (int r_Spatial = 0; r_Spatial < SpatialTiles; ++r_Spatial)
135	{
136		{
137			int g_Y = TileCoordinates.g_TileY + TileCoordinates.Warp / 4 + r_Spatial / 2;
138			int g_X = TileCoordinates.g_TileX + r_Spatial % 2;
139			const bool bValid = ResolveSpatialProjectionInputTile(g_Y, g_X, TileCoordinates);
140			const uint64_t g_ResidualTileBase =
141				Arguments.g_Residual +
142				uint64_t(g_Y * TileCoordinates.g_TilesWide + g_X) * Profile::SpatialTileBytes +
143				TileCoordinates.g_OutputChannel * 16 * Profile::ElementBytes + TileCoordinates.Lane * 16;
144			{
145				#pragma unroll
146				for (int r_ChannelPair = 0; r_ChannelPair < 2; ++r_ChannelPair)
147				{
148					const uint4 r_PackedResidual =
149						bValid
150							? __ldcg(reinterpret_cast<const uint4*>(g_ResidualTileBase + r_ChannelPair * 512))
151							: make_uint4(0, 0, 0, 0);
152					const uint32_t r_PackedResidualWords[4] = {r_PackedResidual.x, r_PackedResidual.y,
153															   r_PackedResidual.z, r_PackedResidual.w};
154					#pragma unroll
155					for (int r_GroupInPair = 0; r_GroupInPair < 2; ++r_GroupInPair)
156					{
157						const int r_ChannelGroup = r_ChannelPair * 2 + r_GroupInPair;
158						auto& r_AccumulatorWords =
159							r_Accumulator.r_AccumulatorWords[r_Spatial][r_ChannelGroup];
160
161						// E4 storage interleaves the two N8 groups; restore MMA accumulator order.
162						r_AccumulatorWords[0] =
163							HalfMul(DecodeE4(uint16_t(r_PackedResidualWords[r_GroupInPair * 2])),
164									r_ResidualScales[r_ChannelGroup][0]);
165						r_AccumulatorWords[1] =
166							HalfMul(DecodeE4(uint16_t(r_PackedResidualWords[r_GroupInPair * 2 + 1])),
167									r_ResidualScales[r_ChannelGroup][0]);
168						r_AccumulatorWords[2] =
169							HalfMul(DecodeE4(uint16_t(r_PackedResidualWords[r_GroupInPair * 2] >> 16)),
170									r_ResidualScales[r_ChannelGroup][1]);
171						r_AccumulatorWords[3] =
172							HalfMul(DecodeE4(uint16_t(r_PackedResidualWords[r_GroupInPair * 2 + 1] >> 16)),
173									r_ResidualScales[r_ChannelGroup][1]);
174					}
175				}
176			}
177		}
178	}
179
180	// Keep K sequential to retain Half accumulation order and the native ring
181	// lifecycle. Prefetch next weights before waiting, then recycle the old stage.
182	#pragma unroll 1
183	for (int ReductionTile = 0; ReductionTile < Profile::ReductionTiles; ++ReductionTile)
184	{
185		uint4 r_Input[SpatialTiles][2];
186		#pragma unroll
187		for (int r_Spatial = 0; r_Spatial < SpatialTiles; ++r_Spatial)
188			#pragma unroll
189			for (int r_KSubtile = 0; r_KSubtile < 2; ++r_KSubtile)
190				r_Input[r_Spatial][r_KSubtile] =
191					*reinterpret_cast<const uint4*>(s_Storage + (ReductionTile % StageCount) * 4096 +
192													(r_Spatial + TileCoordinates.Warp / 4 * 2) * 1024 +
193													r_KSubtile * 512 + TileCoordinates.Lane * 16);
194		AccumulateTile<Profile::Precision>(r_Accumulator, r_Input, r_Weights);
195		if (ReductionTile + 1 < Profile::ReductionTiles)
196		{
197			LoadWeights(ReductionTile + 1);
198			WaitInput(ReductionTile + 1);
199		}
200
201		if (ReductionTile + StageCount < Profile::ReductionTiles)
202			IssueInput(ReductionTile + StageCount);
203	}
204
205	// Write each projected tile in its selected physical output layout.
206	#pragma unroll
207	for (int r_Spatial = 0; r_Spatial < SpatialTiles; ++r_Spatial)
208	{
209		const int g_Y = TileCoordinates.g_TileY + TileCoordinates.Warp / 4 + r_Spatial / 2;
210		const int g_X = TileCoordinates.g_TileX + r_Spatial % 2;
211		if (g_Y >= TileCoordinates.g_TilesHigh || g_X >= TileCoordinates.g_TilesWide)
212			continue;
213		{
214			const uint64_t g_OutputTileBase =
215				Arguments.g_Output +
216				uint64_t(g_Y * TileCoordinates.g_TilesWide + g_X) * Profile::SpatialTileBytes +
217				TileCoordinates.g_OutputChannel * 16 * Profile::ElementBytes + TileCoordinates.Lane * 16;
218			{
219				#pragma unroll
220				for (int r_ChannelPair = 0; r_ChannelPair < 2; ++r_ChannelPair)
221				{
222					const auto& r_LowerChannelWords =
223						r_Accumulator.r_AccumulatorWords[r_Spatial][2 * r_ChannelPair];
224					const auto& r_UpperChannelWords =
225						r_Accumulator.r_AccumulatorWords[r_Spatial][2 * r_ChannelPair + 1];
226					const uint4 r_OutputVector =
227						make_uint4(PackHalfPairsE4(r_LowerChannelWords[0], r_LowerChannelWords[2]),
228								   PackHalfPairsE4(r_LowerChannelWords[1], r_LowerChannelWords[3]),
229								   PackHalfPairsE4(r_UpperChannelWords[0], r_UpperChannelWords[2]),
230								   PackHalfPairsE4(r_UpperChannelWords[1], r_UpperChannelWords[3]));
231					StoreNoAllocate(g_OutputTileBase + r_ChannelPair * 512, r_OutputVector);
232				}
233			}
234		}
235	}
236
237	{
238		// Pool the unquantized accumulators, then publish the single downsampled tile.
239		FSpatialProjectionAccumulator<1> r_Pooled;
240		#pragma unroll
241		for (int r_ChannelGroup = 0; r_ChannelGroup < 4; ++r_ChannelGroup)
242			#pragma unroll
243			for (int r_N8 = 0; r_N8 < 2; ++r_N8)
244				#pragma unroll
245				for (int r_RowHalf = 0; r_RowHalf < 2; ++r_RowHalf)
246				{
247					const auto& r_LeftTileWords =
248						r_Accumulator.r_AccumulatorWords[r_RowHalf * 2][r_ChannelGroup];
249					const auto& r_RightTileWords =
250						r_Accumulator.r_AccumulatorWords[r_RowHalf * 2 + 1][r_ChannelGroup];
251					r_Pooled.r_AccumulatorWords[0][r_ChannelGroup][r_N8 * 2 + r_RowHalf] =
252						PoolHorizontalWords(r_LeftTileWords[r_N8 * 2], r_LeftTileWords[r_N8 * 2 + 1],
253											r_RightTileWords[r_N8 * 2], r_RightTileWords[r_N8 * 2 + 1]);
254				}
255
256		FSpatialProjectionTileCoordinates DownsampledCoordinates = TileCoordinates;
257		DownsampledCoordinates.g_TilesHigh = Arguments.DownsampledHeight / 4;
258		DownsampledCoordinates.g_TilesWide = Arguments.DownsampledWidth / 4;
259		DownsampledCoordinates.g_TileY /= 2;
260		DownsampledCoordinates.g_TileX /= 2;
261		#pragma unroll
262		for (int r_Spatial = 0; r_Spatial < 1; ++r_Spatial)
263		{
264			const int g_Y = DownsampledCoordinates.g_TileY + DownsampledCoordinates.Warp / 4 + r_Spatial / 2;
265			const int g_X = DownsampledCoordinates.g_TileX + r_Spatial % 2;
266			if (g_Y >= DownsampledCoordinates.g_TilesHigh || g_X >= DownsampledCoordinates.g_TilesWide)
267				continue;
268			{
269				const uint64_t g_OutputTileBase =
270					Arguments.g_DownsampledOutput +
271					uint64_t(g_Y * DownsampledCoordinates.g_TilesWide + g_X) * Profile::SpatialTileBytes +
272					DownsampledCoordinates.g_OutputChannel * 16 * Profile::ElementBytes +
273					DownsampledCoordinates.Lane * 16;
274				{
275					#pragma unroll
276					for (int r_ChannelPair = 0; r_ChannelPair < 2; ++r_ChannelPair)
277					{
278						const auto& r_LowerChannelWords =
279							r_Pooled.r_AccumulatorWords[r_Spatial][2 * r_ChannelPair];
280						const auto& r_UpperChannelWords =
281							r_Pooled.r_AccumulatorWords[r_Spatial][2 * r_ChannelPair + 1];
282						const uint4 r_OutputVector =
283							make_uint4(PackHalfPairsE4(r_LowerChannelWords[0], r_LowerChannelWords[2]),
284									   PackHalfPairsE4(r_LowerChannelWords[1], r_LowerChannelWords[3]),
285									   PackHalfPairsE4(r_UpperChannelWords[0], r_UpperChannelWords[2]),
286									   PackHalfPairsE4(r_UpperChannelWords[1], r_UpperChannelWords[3]));
287						StoreNoAllocate(g_OutputTileBase + r_ChannelPair * 512, r_OutputVector);
288					}
289				}
290			}
291		}
292	}
293#else
294	// Keep the exported entry on older targets, but never silently skip FP8 work.
295	__trap();
296#endif
297}
