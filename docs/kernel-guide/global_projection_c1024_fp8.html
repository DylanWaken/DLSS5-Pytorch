01. The whole problem

global_projection_c1024_fp8 belongs to the C1024 bottleneck, records 31–38. It projects the 32 attention heads, concatenated into A[T,1024], through Wₒ[1024,1024] and adds the separately scaled FFN residual Z. With row-vector notation the equation is Y[t,n]=Publish(Σₖ A[t,k]W[k,n]+attn_scale[n]·Z[t,n]). The result is logically [T,1024]. The scale has 1024 channel values and broadcasts over tokens. There is no activation or matrix bias in this entry.

The architecture’s 4K example has H=36,W=60,T=2160. Use T=BatchCount·TokensPerBatch; the prepared plan runs batch one. Inputs, matrix operands and final output use FP8, while the residual scale and deployed arithmetic use Half. The architecture document locates the operation. Our first task is to implement its dependency graph correctly; tile shape, reduction partition and scratch lifetime are decisions to make next.

Establish the mathematical dependency before choosing a tile

Build two tests before changing ownership. With W=0, output must be the published scaled residual. With the residual zero and a one-hot input, only the corresponding weight row should contribute at that token. The scalar loop passes these dependency tests, but rereads each 1024-value input row for 1024 outputs and each weight column for 2160 tokens. A later residual pass would also reread and rewrite the 2,211,840 output elements. Group outputs to attack repeated operands, then seed the residual inside the matrix accumulator to remove that extra pass.

These transformations need a separate numerical ledger. The model equation permits reassociation over real numbers; the deployed Half program does not. We will first derive why splitting K is a plausible work-distribution candidate, then restore the exact existing four-part sum as part of the reproduction contract. No alternative tile or split count on this page has a measured A/B result.

02. One CTA: its concrete subproblem

First give one CTA a rectangle of complete outputs, with no K split. For M rows and N columns, each A value can serve N outputs and each B value can serve M. Under an ideal once-per-CTA operand-load model the reduction consumes (M+N)·K·1 operand bytes for 2·M·N·K operations. For a square tile this is M/1 operations per operand byte: a 64×64 tile gives 64, while 128×128 gives 128. These are reuse calculations, not measured DRAM intensity; padding, caching, duplicate warp loads and publication traffic are omitted.

Do not maximize that ratio without counting registers. With 128 threads and two Half results per word, the accumulator requirement is M·N/256 words per lane. Increasing 128×128 to 128×256 doubles C from 64 to 128 words; a 256×256 tile would need 256 words for C alone. Smaller tiles leave more operand/address capacity and more CTAs, but reload panels more often. The middle candidate is the source’s concrete compromise.

For this narrower N1024 output, the same tile yields only 17·8=136 XY CTAs. A two-way K split would expose 272 logical CTAs; four slices expose 544, with 256 reduction channels per slice. This explains a plausible motivation for the source’s four-way decomposition, but the source does not record its tuning history. Splitting does not shrink C: each partial still has 128×128 results. It exchanges a shorter dot loop and more schedulable work for global Half partial updates, counters and a changed summation order. Once reproducing this deployed kernel, that four-part order becomes a numerical requirement.

Accept the split candidate only with an explicit merge contract

The extra partial CTAs are useful only if they still implement one residual and one output. Partition K into [0,256),[256,512),[512,768),[768,1024). Define C₀ to start from HalfMul(scale,residual), and C₁/C₂/C₃ to start from zero. This makes the residual appear exactly once. Seeding all four partials fails the W=0 test immediately; moving the residual to the end can pass that test while changing nonzero-weight rounding.

Make the merge deterministic: P₀=C₀, P₁=HalfAdd(P₀,C₁), P₂=HalfAdd(P₁,C₂), final=HalfAdd(P₂,C₃). Reserve a separate global Half P; convert to E4M3 only after the last add, because early byte publication changes all later sums. Every intermediate update adds global traffic and a dependency. An unordered atomic merge would discard the selected Half association, so it is not a drop-in implementation of this contract.

03. Warp and thread ownership

Partition the 128×128 partial into a 2×2 array of 64×64 warp tiles. Starting from an m16n8k32 instruction, that is four M16 fragments and eight N8 fragments per warp. Pair adjacent N8 fragments into N16 so one loaded uint4 B vector supplies both. The resulting C[4][4][4] uses 64 Half2 words/lane regardless of the K-split count. This is why splitting shortens the dot but does not solve accumulator pressure.

Retain each A fragment while visiting the four N16 groups, and each B fragment while visiting four M16 groups. A one-fragment-per-warp baseline would reload those operands for each neighboring result tile; the larger register tile buys reuse at the cost of live C. Set lane=threadIdx.x and warp=threadIdx.y in a 32×4 block, then derive lane fields from the native instruction rather than giving each thread an independent dot.

One instruction computes a 16-token × 8-output-channel tile with a reduction of 32 channels. All 32 lanes participate in the same matrix operation. Each lane supplies four 32-bit A words, two 32-bit B words, and two 32-bit C words. Each C word contains two Half accumulators, so a lane owns four output elements. A source loop over output groups or reduction panels repeats this operation; it does not launch a new warp.

The exact instruction on this path is mma.sync.aligned.m16n8k32.row.col.f16.e4m3.e4m3.f16. Both the accumulator input and output are Half. Do not replace its numerical contract with FP32 accumulation when constructing an exact oracle. For the FP8 path, packing to E4M3 is a distinct rounding step; for the FP16 path a packed word simply holds two Half values.

Let lane L run from 0 to 31, g = L // 4 and q = L % 4. The matrix coordinates below describe instruction operands after any kernel-specific loads and shuffles. Storage layouts are designed to supply these coordinates cheaply.

04. Resource budget

Choose the reduction step and storage role together. K32 gives one A stage of 128·32·1=4,096 bytes. The step is a whole number of native MMA K panels, so producer copies need no partial-panel rearrangement. A synchronous one-stage candidate needs 4,104 bytes including its barrier; two need 8,208; three need 12,312. Each added slot buys a possible future operand, not an automatic amount of latency hiding.

Staging B as well is a plausible alternative: its CTA panel is 128·32·1=4,096 bytes, so a 2-stage B ring would add 8,192 data bytes to the allocation below. The source instead loads packed B directly into registers and reuses it over four M16 fragments. That avoids B shared copies and shared capacity, but the two token warps load the same B panel separately and depend on hardware caching. Keep both costs in the design ledger; a cache hint is not evidence that those duplicate loads are free.

Now express the chosen candidate as actual source objects. A uint4 is four 32-bit words; a Half2 word holds two values. The resulting declaration is exactly 8,208 shared bytes per CTA, including every 8-byte barrier. Alignment constrains the base address; it does not add 512 bytes to the declared size.

05. Execution and scheduling

There are two independent scheduling problems. Inside one partial CTA, hide A transfer behind matrix work without overwriting live shared data. Between partial CTAs, let computation proceed but publish P in split order. Implement and test the first with a blocking single-slot loop; implement the second initially as four complete launches in one stream. Resident-counter mode is a later scheduling change, valid only when its waiting CTAs cannot prevent producers from being scheduled.

Derive two separate conditions for reusing a shared slot

A correct blocking loop already waits after filling a slot and after consuming it. An asynchronous version must preserve both meanings: new bytes have arrived and old readers have retired. Give each of the 2 slots its own 8-byte mbarrier. Lane 0 of warp 0 initializes it for 128 thread arrivals, then synchronize the CTA before any copy. On SM90+, IsCopyProducer elects one lane per participating warp to issue ordinary-address cp.async.bulk with the expected completion byte count. On SM80/89, every lane instead issues 16-byte cp.async.cg stripes and attaches its copies with cp.async.mbarrier.arrive. Thus a 512-byte producer panel takes one stripe/lane and a 1024-byte panel takes two.

Use ArriveAndWait to obtain and wait on the current phase token. Reusing a barrier address does not reuse its previous ready state; attached copy completion also belongs to that phase. To test the resulting schedule, compare a blocking single-slot diagnostic implementation with the ring across several wraparounds, including missing groups. A mismatch appearing only after wraparound points first to slot retirement or phase reuse. The final NCU copy/barrier opcodes can verify that asynchronous instructions executed; they cannot prove absence of a race for all schedules.

Do not add an XOR swizzle or ldmatrix merely because another GEMM tutorial uses them. Those solve a different shared-to-register map. Here the producer provides native fragment vectors, and consumers load those vectors directly. Likewise, this path does not allocate TMEM or use a tensor-map descriptor or warp-group MMA. Each extra transform would need to preserve the already-derived operand map and justify its added work.

06. Trace one token through the source

Follow token 83 and, within it, Y[83,34]. Token 83 is group 5, row 3; it belongs to token CTA 0, warp 2, M16 fragment 1, lane 13’s first output row. Lane 13 also carries token 91 because the instruction’s output fragment has two row halves. We retain token 83 as the trace identity throughout: global packed input → shared operand stage → A/B registers → Half accumulator → ordered split partials → final output. Adjacent channels and lanes appear only when the collective instruction requires them.

A global allocation is device memory addressed by a pointer; loads can be served by hardware-managed L2 and, depending on the instruction, L1. A cache hit is not another program-visible tensor and the source does not guarantee cache residency. __ldca permits caching at all levels; __ldcg and PTX .cg select global-level caching that bypasses L1. An eviction or no_allocate hint is a performance policy, not a publication barrier.

Shared memory is an explicitly indexed block-local allocation. Another warp may read a producer's values only after the required block barrier or completed asynchronous-copy protocol. A warp shuffle exchanges register values among its active lanes; it does not address shared memory. Arrays named r_… express per-thread values, but only compiler output establishes whether they stay in physical registers or spill to local memory. Tensor-core accumulator fragments are also register operands. These kernels use mma.sync, not TMEM.

Reconstruct one synchronous split before introducing overlap

This scaffold specifies where each dependency belongs; the following milestones implement and verify its symbolic helpers. It deliberately exposes copy and barrier time between tiles, giving us a simple comparison for the later 2-slot ring. The final candidate uses 8192 shared data bytes plus 16 barrier bytes. Its two-slot pipeline begins with one ready stage and peels the final MMA out of the loop. B has a register-fragment lifetime instead of its own shared ring; compilation will determine its physical allocation.

Implementation milestone 1: make a packed panel round-trip correctly

Before issuing a matrix instruction, implement the scalar pack/decode map and round-trip distinct token/channel tags. The deployment pointers are opaque packed buffers, so a dense row-major fixture would test the wrong contract. Group 16 rows together. One native M16×K32 A panel consumes 512 bytes, distributed as 32 lanes ×16 bytes. For input width K and element size E, group g begins at g·16·K·E. Advance a reduction step in whole panels, and give lane L the vector at L·16. This places four words in the instruction’s required register order without an in-kernel transpose.

A packed B panel for 16 output channels also occupies 512 bytes. One lane’s uint4 supplies two N8 fragments: the first two words belong to the first N8, the next two words to the second. Across K panels, the record advances by N·32 bytes, where this kernel’s N is 1024. The equality follows from 32 reduction values × 1 bytes per value =32 bytes per output column. A cache-all vector load fetches those words directly to registers.

The FP8 matrix’s natural-channel decoder first applies inverse_packed_input_index(k), then packed_weight_index. This permutation is essential: a native MMA K coordinate and a model channel are different labels. The input producer’s packing and the weight row permutation agree. When building fixtures, use those maps together; blindly writing natural-channel rows into the raw byte record does not create the intended matrix.

Implementation milestone 2: build a correct partial, including residual ownership

Keep synchronous copies and one split selected explicitly while implementing these addresses. Decode token 83’s A and B operands, seed the residual only in split 0, and compare each split’s saved Half result before adding any inter-CTA protocol. This separates a wrong packed stride from a wrong merge or wait.

Within one split, the reduction advances by K32, giving 8 steps. One 16-token group’s slab contains 32·16·1=512 bytes. Its global base is A+(g·1024+s·256+i·32)·16·1. The eight groups together occupy 4096 bytes per shared stage. This specialization copies 512 bytes per producer operation, so 1 producer warp positions cooperate per group. In the source’s unified copy loop, copySlot=warp+4·Copy, group=firstGroup+floor(copySlot/1), and destination=stage·4096+copySlot·512. Projection’s 512-byte copies separate the native K panels across producer positions.

The consumer A vector is at shared (i mod2)·4096+floor(warp/2)·4·512+lane·16+m·512+kSubtile·512. W’s register vector starts at W+(s·256+i·32)·1024·1+outputChannel·32+lane·16+kSubtile·32768+n16·512. There are 1 native K subtiles per step. The fixed 32768 stride is 1024 output columns ×32 bytes per native K panel; it is independent of the scalar element width.

For a Half partial, the address is partial+(g·1024+outputChannel)·32+lane·16+n16·512. The factor 32 is 16 tokens ×2 bytes. A residual vector instead uses the working element width: Z+(g·1024+outputChannel)·16·1+lane·16+publicationPanel·512. Scale pairs are always Half, appended at W+1024·1024·1; within that tail, the byte offset is 2·(outputChannel+16·n16+8·n8+2·(lane mod4)). The example’s n16=2,n8=0,lane 13 therefore selects scale channels 34/35, beginning 68 bytes beyond the matrix.

The source supports two protocols. With OrderedSplit=0, blockIdx.z is the logical split. A later split may compute its matrix partial while its predecessor runs, but before touching the predecessor’s global partial it polls the corresponding counter until the recorded split is available.   2. Each split contributes: place one nonzero input/weight pair in each K region and compare saved P₀,P₁,P₂ and final. They must follow the specified Half addition order. Values chosen near Half rounding boundaries distinguish this from a reassociated or FP32 sum.
  3. Scratch format: inspect the first three partials as Half, not E4M3, and verify no final FP8 vector is considered ready before split 3.
  4. Address ownership: use the worked token 83/channel 34 example and nearby lane/channel groups. Every output vector must be written once per publication phase, and guard bytes must remain unchanged.
  5. Schedule equivalence: run both admitted resident mode and forced ordered split mode on supported hardware; final bytes should agree. Include more XY blocks than fit in one wave to exercise the host’s capacity fallback.

12#if __CUDA_ARCH__ < 900
13	static_assert(Profile::s_InitialStages == 1 && Profile::s_StageCount == 2,
14				  "Early prefetch requires one initial stage and two alternating slots");
15#endif
16	__shared__ __align__(512) unsigned char s_Storage[Profile::s_BarrierOffset + Profile::s_StageCount * 8];
17	const int g_Tokens = Parameters.BatchCount * Parameters.TokensPerBatch;
18	const int g_TokenTiles = (g_Tokens + 127) / 128;
19	const int g_ChannelBlock = int(blockIdx.x) / g_TokenTiles;
20	const int Warp = threadIdx.y, Lane = threadIdx.x;
21
22	// Small devices execute one K split per stream-ordered launch. Zero keeps
23	// the native grid-Z schedule; the launcher supplies Split + 1 otherwise.
24	const int Split = Parameters.OrderedSplit ? int(Parameters.OrderedSplit) - 1 : int(blockIdx.z);
25	const FGlobalContractTileCoordinates TileCoordinates{(int(blockIdx.x) % g_TokenTiles) * 8,
26														 g_ChannelBlock * 128 + (Warp & 1) * 64,
27														 bFp8 ? ((g_Tokens + 31) / 32) * 2
28															  : (g_Tokens + 15) / 16,
29														 g_ChannelBlock,
30														 Lane,
31														 Warp,
32														 Split,
33														 !bFp8 && uint32_t(g_Tokens + 14) < 31};
34
35	// The initial fill and later refills share this exact staged input copy.
36	const auto StageInput = [&](int ReductionTile)
37	{
38		const int s_Stage = ReductionTile % Profile::s_StageCount;
39		const int s_Barrier = Profile::s_BarrierOffset + s_Stage * 8;
40
41		// Contraction coalesces both K fragments in each 16-token group. Half
42		// attention projection instead assigns each K fragment to a separate warp.
43		#pragma unroll
44		for (int Copy = 0; Copy < Profile::s_CopiesPerWarp; ++Copy)
45		{
46			const int g_Group = TileCoordinates.bBroadcastInput
47									? 0
48									: TileCoordinates.g_TokenGroupBase +
49										  (TileCoordinates.Warp + Copy * 4) / Profile::s_ProducersPerGroup;
50			const int s_Destination =
51				s_Stage * Profile::s_StageBytes + (TileCoordinates.Warp + Copy * 4) * Profile::s_CopyBytes;
52			if (g_Group < TileCoordinates.g_PaddedGroups)
53			{
54				if (IsCopyProducer(0xffffffffu))
55				{
56					const uint64_t g_Source =
57						Parameters.g_Input +
58						uint64_t(g_Group * Profile::InputChannels +
59								 TileCoordinates.Split * Profile::SplitChannels +
60								 ReductionTile * Profile::ReductionStep) *
61							16 * Profile::ElementBytes +
62						(TileCoordinates.Warp % Profile::s_ProducersPerGroup) * Profile::s_CopyBytes;
63					CopyBulk(s_Storage, s_Destination, g_Source, Profile::s_CopyBytes, s_Barrier);
64					BarrierExpect(s_Storage, s_Barrier, Profile::s_CopyBytes);
65				}
66			}
67			else
68			{
69				#pragma unroll
70				for (int s_Subtile = 0; s_Subtile < Profile::s_CopyBytes / 512; ++s_Subtile)
71					*reinterpret_cast<uint4*>(s_Storage + s_Destination + s_Subtile * 512 +
72											  TileCoordinates.Lane * 16) = make_uint4(0, 0, 0, 0);
73			}
74		}
75	};
76
77	// Only a completed stage can feed the register MMA tile.
78	const auto WaitStage = [&](int ReductionTile)
79	{
80		const int s_Barrier = Profile::s_BarrierOffset + (ReductionTile % Profile::s_StageCount) * 8;
81		ArriveAndWait(s_Storage, s_Barrier);
82	};
83
84	// Initialize the shared copy barriers before any warp issues input transactions.
85	if (Lane == 0 && Warp == 0)
86		#pragma unroll
87		for (int s_Stage = 0; s_Stage < Profile::s_StageCount; ++s_Stage)
88			BarrierInit(s_Storage, Profile::s_BarrierOffset + s_Stage * 8, blockDim.x * blockDim.y);
89	__syncthreads();
90
91	uint4 r_Weights[Profile::ReductionSubtiles][4];
92
93	// Prefetch weights without changing the ring dependency order.
94	const auto LoadWeights = [&](int ReductionTile)
95	{
96		const uint64_t g_WeightTileBase = Parameters.g_PackedWeights +
97										  uint64_t(TileCoordinates.Split * Profile::SplitChannels +
98												   ReductionTile * Profile::ReductionStep) *
99											  1024 * Profile::ElementBytes +
100										  TileCoordinates.g_OutputChannel * 32 + TileCoordinates.Lane * 16;
101		#pragma unroll
102		for (int r_KSubtile = 0; r_KSubtile < Profile::ReductionSubtiles; ++r_KSubtile)
103			#pragma unroll
104			for (int r_ChannelGroup = 0; r_ChannelGroup < 4; ++r_ChannelGroup)
105				r_Weights[r_KSubtile][r_ChannelGroup] = __ldca(reinterpret_cast<const uint4*>(
106					g_WeightTileBase + r_KSubtile * 32768 + r_ChannelGroup * 512));
107	};
108
109	// Prime the weight registers and input pipeline before entering the reduction loop.
110	LoadWeights(0);
111	#pragma unroll
112	for (int s_InitialStage = 0; s_InitialStage < Profile::s_InitialStages; ++s_InitialStage)
113		StageInput(s_InitialStage);
114	WaitStage(0);
115	FGlobalContractAccumulator r_Accumulator{};
116
117	// Only the first K split seeds the accumulator from the residual.
118	if (TileCoordinates.Split == 0)
119	{
120		// The record appends 1024 Half scales to the matrix. Lane's two adjacent
121		// channels share a packed scale; words 0/1 and 2/3 belong to separate N8s.
122		uint32_t r_ResidualScales[4][2];
123		#pragma unroll
124		for (int r_ChannelGroup = 0; r_ChannelGroup < 4; ++r_ChannelGroup)
125			#pragma unroll
126			for (int r_N8 = 0; r_N8 < 2; ++r_N8)
127				r_ResidualScales[r_ChannelGroup][r_N8] = *reinterpret_cast<const uint32_t*>(
128					Parameters.g_PackedWeights + Profile::MatrixBytes +
129					(TileCoordinates.g_OutputChannel + r_ChannelGroup * 16 + r_N8 * 8 +
130					 (TileCoordinates.Lane & 3) * 2) *
131						2);
132
133		#pragma unroll
134		for (int r_Spatial = 0; r_Spatial < 4; ++r_Spatial)
135		{
136			const int g_Group =
137				TileCoordinates.bBroadcastInput
138					? 0
139					: TileCoordinates.g_TokenGroupBase + (TileCoordinates.Warp >> 1) * 4 + r_Spatial;
140			const uint64_t g_ResidualTileBase =
141				Parameters.g_Residual +
142				uint64_t(g_Group * 1024 + TileCoordinates.g_OutputChannel) * 16 * Profile::ElementBytes +
143				TileCoordinates.Lane * 16;
144			{
145				#pragma unroll
146				for (int r_ChannelPair = 0; r_ChannelPair < 2; ++r_ChannelPair)
147				{
148					const uint4 r_PackedResidual =
149						g_Group < TileCoordinates.g_PaddedGroups
150							? __ldcg(reinterpret_cast<const uint4*>(g_ResidualTileBase + r_ChannelPair * 512))
151							: make_uint4(0, 0, 0, 0);
152					const uint32_t r_PackedResidualWords[4] = {r_PackedResidual.x, r_PackedResidual.y,
153															   r_PackedResidual.z, r_PackedResidual.w};
154					#pragma unroll
155					for (int r_InPair = 0; r_InPair < 2; ++r_InPair)
156					{
157						const int r_ChannelGroup = r_ChannelPair * 2 + r_InPair;
158						auto& r_AccumulatorWords =
159							r_Accumulator.r_AccumulatorWords[r_Spatial][r_ChannelGroup];
160						r_AccumulatorWords[0] =
161							HalfMul(DecodeE4(uint16_t(r_PackedResidualWords[r_InPair * 2])),
162									r_ResidualScales[r_ChannelGroup][0]);
163						r_AccumulatorWords[1] =
164							HalfMul(DecodeE4(uint16_t(r_PackedResidualWords[r_InPair * 2 + 1])),
165									r_ResidualScales[r_ChannelGroup][0]);
166						r_AccumulatorWords[2] =
167							HalfMul(DecodeE4(uint16_t(r_PackedResidualWords[r_InPair * 2] >> 16)),
168									r_ResidualScales[r_ChannelGroup][1]);
169						r_AccumulatorWords[3] =
170							HalfMul(DecodeE4(uint16_t(r_PackedResidualWords[r_InPair * 2 + 1] >> 16)),
171									r_ResidualScales[r_ChannelGroup][1]);
172					}
173				}
174			}
175		}
176	}
177
178	// Native two-stage code peels the final MMA tile out of the prefetch loop.
179	// Keeping that drain explicit removes a per-iteration tail branch. The
180	// three-stage Half contraction retains its distinct refill lifecycle.
181	#pragma unroll 1
182	for (int ReductionTile = 0;
183		 ReductionTile < Profile::ReductionTiles - (Profile::s_InitialStages == 1 ? 1 : 0); ++ReductionTile)
184	{
185#if __CUDA_ARCH__ < 900
186		// WaitStage(i) completed every thread's arrival after Consume(i-1),
187		// releasing that old slot. Prefetch i+1 into it while i's MMA runs in
188		// the other slot; the weight registers still hold i until consumption.
189		StageInput(ReductionTile + 1);
190#endif
191		ConsumeGlobalContractInputStage<Profile>(r_Accumulator, r_Weights, s_Storage, ReductionTile,
192												 TileCoordinates);
193		{
194#if __CUDA_ARCH__ >= 900
195			StageInput(ReductionTile + 1);
196#endif
197			LoadWeights(ReductionTile + 1);
198			WaitStage(ReductionTile + 1);
199		}
200	}
201
202	ConsumeGlobalContractInputStage<Profile>(r_Accumulator, r_Weights, s_Storage, Profile::ReductionTiles - 1,
203											 TileCoordinates);
204
205	// Compile-time split policy keeps the native branch outside all store loops.
206	const auto PublishFragments = [&](auto PublicationTag)
207	{
208		constexpr auto Publication = decltype(PublicationTag)::value;
209		const bool bFirstSplit = Publication == EGlobalContractSplitPublication::Runtime
210									 ? TileCoordinates.Split == 0
211									 : Publication == EGlobalContractSplitPublication::First;
212		const bool bIntermediateSplit = Publication == EGlobalContractSplitPublication::Runtime
213											? TileCoordinates.Split < 3
214											: Publication == EGlobalContractSplitPublication::Intermediate;
215
216		// Serial publication preserves the DLL's Half rounding between K splits.
217		// FP8 keeps partial sums in a separate Half buffer until the fourth split.
218		const uint64_t g_PartialSums = bFp8 ? Parameters.g_SplitAccumulator : Parameters.g_Output;
219		#pragma unroll
220		for (int r_Spatial = 0; r_Spatial < 4; ++r_Spatial)
221		{
222			const int g_Group =
223				TileCoordinates.g_TokenGroupBase + (TileCoordinates.Warp >> 1) * 4 + r_Spatial;
224			if (g_Group < TileCoordinates.g_PaddedGroups)
225			{
226				const uint64_t g_HalfBase = g_PartialSums +
227											uint64_t(g_Group * 1024 + TileCoordinates.g_OutputChannel) * 32 +
228											TileCoordinates.Lane * 16;
229				#pragma unroll
230				for (int r_ChannelGroup = 0; r_ChannelGroup < 4; ++r_ChannelGroup)
231				{
232					auto& r_AccumulatorWords = r_Accumulator.r_AccumulatorWords[r_Spatial][r_ChannelGroup];
233					const uint64_t g_PartialSumAddress = g_HalfBase + r_ChannelGroup * 512;
234					if (bFirstSplit)
235						StoreNoAllocate(g_PartialSumAddress,
236										make_uint4(r_AccumulatorWords[0], r_AccumulatorWords[1],
237												   r_AccumulatorWords[2], r_AccumulatorWords[3]));
238					else if (bIntermediateSplit)
239						AccumulateExclusiveHalf4(g_PartialSumAddress,
240												 make_uint4(r_AccumulatorWords[0], r_AccumulatorWords[1],
241															r_AccumulatorWords[2], r_AccumulatorWords[3]));
242					else
243					{
244						const uint4 r_PreviousSplitWords = LoadSplitAccumulatorHalf4(g_PartialSumAddress);
245						r_AccumulatorWords[0] = HalfAdd(r_PreviousSplitWords.x, r_AccumulatorWords[0]);
246						r_AccumulatorWords[1] = HalfAdd(r_PreviousSplitWords.y, r_AccumulatorWords[1]);
247						r_AccumulatorWords[2] = HalfAdd(r_PreviousSplitWords.z, r_AccumulatorWords[2]);
248						r_AccumulatorWords[3] = HalfAdd(r_PreviousSplitWords.w, r_AccumulatorWords[3]);
249						{
250						}
251					}
252				}
253				{
254					const bool bFinalSplit = Publication == EGlobalContractSplitPublication::Runtime
255												 ? TileCoordinates.Split == 3
256												 : Publication == EGlobalContractSplitPublication::Final;
257					if (bFinalSplit)
258					{
259						const uint64_t g_OutputBase =
260							Parameters.g_Output +
261							uint64_t(g_Group * 1024 + TileCoordinates.g_OutputChannel) * 16 +
262							TileCoordinates.Lane * 16;
263						#pragma unroll
264						for (int r_ChannelPair = 0; r_ChannelPair < 2; ++r_ChannelPair)
265						{
266							const auto& r_LowerChannelWords =
267								r_Accumulator.r_AccumulatorWords[r_Spatial][r_ChannelPair * 2];
268							const auto& r_UpperChannelWords =
269								r_Accumulator.r_AccumulatorWords[r_Spatial][r_ChannelPair * 2 + 1];
270							StoreNoAllocate(
271								g_OutputBase + r_ChannelPair * 512,
272								make_uint4(PackHalfPairsE4(r_LowerChannelWords[0], r_LowerChannelWords[2]),
273										   PackHalfPairsE4(r_LowerChannelWords[1], r_LowerChannelWords[3]),
274										   PackHalfPairsE4(r_UpperChannelWords[0], r_UpperChannelWords[2]),
275										   PackHalfPairsE4(r_UpperChannelWords[1], r_UpperChannelWords[3])));
276						}
277					}
278				}
279			}
280		}
281	};
282
283	const uint64_t g_SplitCounters =
284		Parameters.g_SplitCounters + (TileCoordinates.g_TokenGroupBase + TileCoordinates.g_ChannelBlock) * 4;
285
286	// Ordered launches complete their predecessor before entering this kernel,
287	// so they never occupy an SM while polling an unscheduled producer.
288	if (Parameters.OrderedSplit == 0 && TileCoordinates.Split > 0)
289	{
290		if (TileCoordinates.Lane == 0 && TileCoordinates.Warp == 0)
291		{
292			while (int32_t(CounterLoadRelaxed(g_SplitCounters)) < TileCoordinates.Split - 1)
293				PollSleep(64);
294#if __CUDA_ARCH__ < 900
295			// Acquire the completed split before any lane reads its Half scratch.
296			AcquireSplitPublication();
297#endif
298		}
299
300		__syncthreads();
301	}
302
303	{
304		// The native epilogue selects first-store, intermediate-reduction or
305		// final-pack once. Keep that uniform choice outside fragment loops.
306		if (TileCoordinates.Split == 0)
307			PublishFragments(std::integral_constant<EGlobalContractSplitPublication,
308													EGlobalContractSplitPublication::First>{});
309		else if (TileCoordinates.Split < 3)
310			PublishFragments(std::integral_constant<EGlobalContractSplitPublication,
311													EGlobalContractSplitPublication::Intermediate>{});
312		else
313			PublishFragments(std::integral_constant<EGlobalContractSplitPublication,
314													EGlobalContractSplitPublication::Final>{});
315	}
316
317	__syncthreads();
318	if (TileCoordinates.Lane == 0 && TileCoordinates.Warp == 0)
319		CounterStoreRelease(g_SplitCounters, TileCoordinates.Split);
320#else
321	// Keep the exported entry on older targets, but never silently skip FP8 work.
322	__trap();
323#endif
324}
