01. The model piece: record 0, renderer features through the first C32 window block

This kernel turns renderer images and scalar controls into 16 Half features per pixel, applies a learned 16→32 adapter, and executes a complete local C32 FFN/attention block. It publishes the full-resolution feature field used as a skip later in the network. It also averages each raw Half 2×2 output cell into a half-resolution C32 field for the encoder. This pooling does not expand the channel count. This document covers the FP16 public entry from its inputs to its final stores.

Each block owns an 8×8 window, or 64 tokens. Four 4×4 physical tiles supply 16-token matrix fragments. The prepared launcher uses one warp, block=(32,1,1), so the 32 CUDA lanes collectively own each matrix tile. All lanes must participate in shuffles and matrix instructions. Spatial predicates control boundary loads and stores without allowing a lane to exit before collective work. The grid is (FullWidth/8,FullHeight/8). The physical image dimensions are multiples of eight; the valid renderer extent can be smaller.

The architecture's transformer sub-block is 32→128→32 FFN, followed by one 32-channel attention head over the 64-token window. Its optimized numerical operations include explicit Half rounding and a recovered attention-weight approximation. We will define them locally below. The adapter, fused matrix operations and head operands use Half on this path. The architecture companion provides the broader encoder–decoder map.

02. Build a scalar oracle for one window

Separate correctness from layout initially. Represent a window as [64,channels], implement the feature or merge operation, then the linear maps, activation, Q/K normalization, attention weights, weighted values and residuals. Preserve every publication boundary and Half arithmetic order. Once that oracle agrees for one window, replace one stage at a time with the packed implementation. A standard library FFN or softmax is useful as a conceptual sketch but cannot be the final bit-level oracle for these recovered formulas.

Here publish means rearrange Half accumulator pairs into the next instruction’s Half operand layout. It does not necessarily mean a global-memory write. The raw adapter/merge and raw FFN residual remain available as Half register fragments even when a published copy is consumed by the next matrix instruction.

03. Define storage and the 16-token instruction

A global allocation is device memory addressed by a pointer; loads can be served by hardware-managed L2 and, depending on the instruction, L1. A cache hit is not another program-visible tensor and the source does not guarantee cache residency. __ldca permits caching at all levels; __ldcg and PTX .cg select global-level caching that bypasses L1. An eviction or no_allocate hint is a performance policy, not a publication barrier.

Shared memory is an explicitly indexed block-local allocation. Another warp may read a producer's values only after the required block barrier or completed asynchronous-copy protocol. A warp shuffle exchanges register values among its active lanes; it does not address shared memory. Arrays named r_… express per-thread values, but only compiler output establishes whether they stay in physical registers or spill to local memory. Tensor-core accumulator fragments are also register operands. These kernels use mma.sync, not TMEM.

One instruction computes a 16-token × 8-output-channel tile with a reduction of 16 channels. All 32 lanes participate in the same matrix operation. Each lane supplies four 32-bit A words, two 32-bit B words, and two 32-bit C words. Each C word contains two Half accumulators, so a lane owns four output elements. A source loop over output groups or reduction panels repeats this operation; it does not launch a new warp.

The exact instruction on this path is mma.sync.aligned.m16n8k16.row.col.f16.f16.f16.f16. Both the accumulator input and output are Half. Do not replace its numerical contract with FP32 accumulation when constructing an exact oracle. For the FP8 path, packing to E4M3 is a distinct rounding step; for the FP16 path a packed word simply holds two Half values.

Let lane L run from 0 to 31, g = L // 4 and q = L % 4. The matrix coordinates below describe instruction operands after any kernel-specific loads and shuffles. Storage layouts are designed to supply these coordinates cheaply.

04. Sample a pixel and assemble its 16 feature channels

Lane L visits local pixels s=L and s=L+32. Pixel coordinates are x=8×block.x+(s%8) and y=8×block.y+s//8. Outside the valid renderer extent, reflect once: x′=2×ValidWidth−x−2, similarly for y. The launcher ensures that one reflection is sufficient. Use reflected coordinates for images but original x/y for the noise hash, so two padded positions that sample the same image texel can still have different noise features.

Normalized image coordinates are ((x′+0.5)/ValidWidth,(y′+0.5)/ValidHeight). Each texture's transform computes NormalizeX×fma(ScaleX,u,BiasX), likewise y. A texture handle is an opaque CUDA texture object, not a byte address you can dereference. The launcher backs it with a float32 HWC4 CUDA array, configures point or linear filtering as requested, and copies the tensor into that array before launch.

The color path explicitly rounds: Half(texture), then a Half subtraction of 0.5, then a Half multiplication by Half(ColorScale+ColorScale). A float affine expression followed by one Half conversion loses intermediate rounding points. History initially equals current color. Only when both history and motion handles exist does the kernel reconstruct a separate history value.

05. Reconstruct history with five filtered samples

The frontend uses a custom cross-shaped cubic reconstruction. Work in pixel-center coordinates. On either axis, set center=floor(position−0.5)+0.5 and clamp f=position−center to [0,1]. The four one-dimensional weights are l=−0.5(f+f³)+f², ml=1+1.5f³−2.5f², r=0.5(f³−f²), and mr=1−l−ml−r. The middle pair becomes one filtered sample with weight m=ml+mr at center+mr/m. The outer sample positions are center−1 and center+2. Clamp all three positions, including the merged middle position, to the valid pixel-center interval [0.5,Extent−0.5].

Apply that construction on x and y. Sample only left, top, center, bottom and right, at products of the corresponding axis weights; omit the four corner products. Divide by the sum of the five retained weights. The source begins its accumulator with the top contribution, then adds left, center, bottom and right with explicit floating-point FMAs. This order and the approximate reciprocal are part of the reproduced arithmetic. A generic 16-tap bicubic filter does not implement this contract.

06. Generate deterministic noise and conditioning features

Noise is computed independently for each original integer pixel position and frame seed. All hash arithmetic is unsigned 32-bit with wraparound. The permutation first shifts its state right by (state>>28)+4, XORs it with the original state, and multiplies by 277803737. The initial state combines x, y and seed with three fixed multipliers and an XOR constant. After the first permutation, compute pixelHash=(hash>>22) XOR hash. Four stream-specific multiply/add pairs applied to pixelHash then feed the same permutation.

For each stream, form u=(((hash>>30) XOR (hash>>8))+1)×2⁻²⁴. The added one avoids log(0). Two Box–Muller pairs compute radii from approximate log2 and square-root instructions, and angles from the second uniform times 2π. Keep radius₀cos(angle₀), radius₀sin(angle₀), and radius₁cos(angle₁). A library random-number generator cannot reproduce this address-derived sequence.

140											ConvertFeatureToHalf(r_ConditioningOverrideGreen)),

142											ConvertFeatureToHalf(CONST_ZERO)));

150							FPreprocessWindowProfile<bFp8>::AdapterOffset;

152	#pragma unroll

156			*reinterpret_cast<const uint4*>(g_Weights + r_ColumnPair * 512 + threadIdx.x * 16);

161	}

164	for (int r_Tile = 0; r_Tile < 4; ++r_Tile)
165	{
166		FWindowAFragment r_Input;
167		#pragma unroll
168		for (int r_Word = 0; r_Word < 4; ++r_Word)
169		{
170			// A word has two adjacent feature channels; its row maps directly
171			// into a 4x4 physical tile, with the row-half distance of two pixels.
172			const int s_Pixel = 4 * (r_Tile & 1) + 32 * (r_Tile >> 1) + ((threadIdx.x / 4) & 3) +
173								8 * (threadIdx.x / 16) + 16 * (r_Word & 1);
174			const uint4& s_Channels = s_Features.s_Plane[r_Word / 2][s_Pixel];
175			r_Input.r_Word[r_Word] = reinterpret_cast<const uint32_t*>(&s_Channels)[threadIdx.x & 3];
176		}
177
178		#pragma unroll
179		for (int r_Column = 0; r_Column < 4; ++r_Column)
180		{
181			r_Adapter[r_Tile].r_Pair[r_Column][0] = 0;
182			r_Adapter[r_Tile].r_Pair[r_Column][1] = 0;
183			MmaWindowFragment<false>(r_Input, r_WeightFragments[r_Column],
184									 r_Adapter[r_Tile].r_Pair[r_Column]);
185		}
186	}

189												 Parameters.g_Output,
190												 Parameters.g_PackedWeights,
191												 Parameters.FullHeight,
192												 Parameters.FullWidth,
193												 0,
194												 0,
195												 r_Adapter};

200		{
201			using FConfig = FPreprocessWindowProfile<bFp8>;
202			const unsigned char* g_PackedWeights =
203				reinterpret_cast<const unsigned char*>(WindowParameters.g_PackedWeights);
204			FWindowActivationTile<bFp8> r_Input[4];
205			FWindowAccumulatorTile<32> r_Ffn[4];
206
207			// Load the per-channel residual scales used by the FFN and attention branches.
208			uint32_t r_FfnScale[4], r_AttentionScale[4];
209			#pragma unroll
210			for (int r_Column = 0; r_Column < 4; ++r_Column)
211			{
212				const int g_ChannelByte = 16 * r_Column + 4 * (threadIdx.x & 3);
213				r_FfnScale[r_Column] = *reinterpret_cast<const uint32_t*>(

215				r_AttentionScale[r_Column] = *reinterpret_cast<const uint32_t*>(

217			}

220			// available tile for reads, as the native entry does; writes remain bounded.
221			#pragma unroll

224				r_Input[r_Tile] = PublishWindow32<bFp8>(WindowParameters.r_Adapter[r_Tile]);

234					}

238			// seed is the scaled input, and its reduction chunks stay in native order.
239			#pragma unroll
240			for (int HiddenPanel = 0; HiddenPanel < 4; ++HiddenPanel)
241			{

243					LoadWindowWeights<bFp8>(g_PackedWeights, 32 * HiddenPanel, 0, 128);
244				const FWindowWeightTile<bFp8> r_Contract = LoadWindowWeights<bFp8>(
245					g_PackedWeights + FConfig::ContractOffset, 0, 32 * HiddenPanel, 32);
246				#pragma unroll

248				{

251					#pragma unroll
252					for (int r_Column = 0; r_Column < 4; ++r_Column)
253						#pragma unroll
254						for (int r_RowHalf = 0; r_RowHalf < 2; ++r_RowHalf)

257					LinearWindow32(PublishWindow32<bFp8>(r_HiddenTile), r_Contract, r_Ffn[r_Tile]);
258				}
259			}
260			#pragma unroll
261			for (int r_Tile = 0; r_Tile < 4; ++r_Tile)
262				r_Input[r_Tile] = PublishWindow32<bFp8>(r_Ffn[r_Tile]);
263
264			// Project the FFN output into Q/K/V fragments and normalize the query/key rows.
265			FWindowActivationTile<bFp8> r_Query[4], r_Key[4];
266			FWindowValueTile<bFp8> r_Value[4];

268				FloatToHalf2(*reinterpret_cast<const uint32_t*>(g_PackedWeights + FConfig::HeadScaleOffset));
269			#pragma unroll
270			for (int ProjectionComponent = 0; ProjectionComponent < 3; ++ProjectionComponent)
271			{
272				const FWindowWeightTile<bFp8> r_Weights = LoadWindowWeights<bFp8>(
273					g_PackedWeights + FConfig::QkvOffset, 32 * ProjectionComponent, 0, 96);
274				#pragma unroll
275				for (int r_Tile = 0; r_Tile < 4; ++r_Tile)
276				{
277					FWindowAccumulatorTile<32> r_Projected{};
278					LinearWindow32(r_Input[r_Tile], r_Weights, r_Projected);
279					if (ProjectionComponent < 2)
280					{
281						if (ProjectionComponent == 0)
282							NormalizeWindow<true>(r_Projected, r_HeadScale);
283						else
284							NormalizeWindow<false>(r_Projected, CONST_HALF2_ONE);
285						if (ProjectionComponent == 0)
286							r_Query[r_Tile] = PublishWindow32<bFp8>(r_Projected);
287						else
288							r_Key[r_Tile] = PublishWindow32<bFp8>(r_Projected);
289					}
290					else
291						#pragma unroll
292						for (int r_Column = 0; r_Column < 4; ++r_Column)
293						{
294							const uint32_t r_LowRows = TransposeM8n8(r_Projected.r_Pair[r_Column][0]);
295							const uint32_t r_HighRows = TransposeM8n8(r_Projected.r_Pair[r_Column][1]);
296							{
297								r_Value[r_Tile].r_Column[r_Column][0] = r_LowRows;
298								r_Value[r_Tile].r_Column[r_Column][1] = r_HighRows;
299							}
300						}
301				}
302			}
303
304			const FWindowWeightTile<bFp8> r_OutputWeights =
305				LoadWindowWeights<bFp8>(g_PackedWeights + FConfig::ProjectionOffset, 0, 0, 32);
306
307			// FP8 follows the native two-query-tile softmax schedule. Keep the tested
308			// FP16 schedule independent until its register pressure is measured.
309			constexpr int CONST_QUERY_TILE_BATCH = bFp8 ? 2 : 1;
310			#pragma unroll
311			for (int r_FirstTile = 0; r_FirstTile < 4; r_FirstTile += CONST_QUERY_TILE_BATCH)
312			{
313				FWindowAccumulatorTile<64> r_Probabilities[CONST_QUERY_TILE_BATCH];
314				#pragma unroll
315				for (int r_LocalTile = 0; r_LocalTile < CONST_QUERY_TILE_BATCH; ++r_LocalTile)
316					r_Probabilities[r_LocalTile] = QueryKeyScores<bFp8>(
317						r_FirstTile + r_LocalTile, g_PackedWeights + FConfig::BiasOffset, r_Query, r_Key);
318				SoftmaxWindow(r_Probabilities[0]);
319
320				#pragma unroll
321				for (int r_LocalTile = 0; r_LocalTile < CONST_QUERY_TILE_BATCH; ++r_LocalTile)
322				{
323					const int r_Tile = r_FirstTile + r_LocalTile;
324					const auto r_Attended = ProbabilityValues<bFp8>(r_Probabilities[r_LocalTile], r_Value);
325					#pragma unroll
326					for (int r_Column = 0; r_Column < 4; ++r_Column)
327						#pragma unroll
328						for (int r_RowHalf = 0; r_RowHalf < 2; ++r_RowHalf)
329							r_Ffn[r_Tile].r_Pair[r_Column][r_RowHalf] = HalfMul(
330								r_Ffn[r_Tile].r_Pair[r_Column][r_RowHalf], r_AttentionScale[r_Column]);
331					LinearWindow32(PublishWindow32<bFp8>(r_Attended), r_OutputWeights, r_Ffn[r_Tile]);
332					r_Output[r_Tile] = r_Ffn[r_Tile];
333
334					{
335						const int g_TileColumns = WindowParameters.Width / 4,
336								  g_TileRows = WindowParameters.Height / 4;
337						const int g_OriginTileX = (int(blockIdx.x) * 8 + WindowParameters.OriginX) / 4;
338						const int g_OriginTileY = (int(blockIdx.y) * 8 + WindowParameters.OriginY) / 4;
339						const int g_TileX = g_OriginTileX + (r_Tile & 1),
340								  g_TileY = g_OriginTileY + (r_Tile >> 1);
341						if (g_TileX >= 0 && g_TileX < g_TileColumns && g_TileY >= 0 && g_TileY < g_TileRows)
342						{
343							#pragma unroll
344							for (int r_Chunk = 0; r_Chunk < FConfig::InputChunks; ++r_Chunk)
345							{
346								const FWindowAFragment r_Output =
347									PublishWindowChunk<bFp8>(r_Ffn[r_Tile], r_Chunk);
348								const uint64_t g_OutputAddress =
349									WindowParameters.g_Output +
350									uint64_t(g_TileY * g_TileColumns + g_TileX) * FConfig::TileBytes +
351									r_Chunk * 512 + int(threadIdx.x) * 16;
352								StoreNoAllocate(g_OutputAddress,
353												make_uint4(r_Output.r_Word[0], r_Output.r_Word[1],
354														   r_Output.r_Word[2], r_Output.r_Word[3]));
355							}
356						}
357					}
358				}
359			}
360		}
361

363		const FWindowDownsampleArguments DownsampledParameters{0,
364															   Parameters.g_Output,
365															   Parameters.g_PackedWeights,
366															   Parameters.g_PooledOutput,
367															   Parameters.FullHeight,
368															   Parameters.FullWidth,
369															   0,
370															   0,
371															   Parameters.PooledHeight,
372															   Parameters.PooledWidth};
373
374		// The input stage pools C32 directly. Later encoder stages additionally
375		// project C -> 2C, which would be an incorrect extra operation here.
376		PublishWindowDownsample<32, bFp8>(DownsampledParameters, 0, r_Pooled);
377		ClearDownsamplePadding<32, 4>(DownsampledParameters);
378	}
