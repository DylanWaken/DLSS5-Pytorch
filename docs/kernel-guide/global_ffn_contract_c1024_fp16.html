01. The whole problem

global_ffn_contract_c1024_fp16 belongs to the C1024 bottleneck, records 31–38. It contracts the activated dense-FFN intermediate U[T,4096] through W₂[4096,1024] and adds the separately scaled original block input X. With row-vector notation the equation is Z[t,n]=Publish(Σₖ U[t,k]W[k,n]+ffn_scale[n]·X[t,n]). The result is logically [T,1024]. The scale has 1024 channel values and broadcasts over tokens. There is no activation or matrix bias in this entry.

The architecture’s 4K example has H=36,W=60,T=2160. This body uses T=BatchCount·TokensPerBatch; the prepared plan runs batch one. Inputs, matrix operands and final output use FP16. Residual scales, accumulators and intermediate split sums use Half. This public FP16 entry owns its complete kernel body. The architecture document locates this operation in the block, while this lesson derives its implementation locally.

Establish the mathematical dependency before choosing a tile

This baseline says one output reads all 4096 channels at one token plus one residual value. There is no communication between token t and token t+1. Assigning one thread to each output would reread each input row for many output columns, and reread the same W columns for every token. Separate residual and publication kernels would add further global reads/writes. Those costs suggest grouping outputs, reusing operand panels and fusing the residual. The scalar equation is a dependency reference; exact deployment equivalence additionally requires the recovered split order and Half rounding described below.

02. One CTA: its concrete subproblem

Let Mtiles=ceil(T/128). For block.x=b, channelBlock=floor(b/Mtiles), firstGroup=(b modMtiles)·8 and outputChannel=128·channelBlock+64·(warp mod2). The warp consumes groups firstGroup+4·floor(warp/2)+m, m=0…3. Split selection is OrderedSplit ? OrderedSplit−1 : blockIdx.z. Unlike an ordinary complete GEMM, this CTA computes only 1024 of the 4096 input channels. Four such partial computations contribute to the same output addresses.

The CTA owns one reduction slice, so define its partial result

Partition K into ranges [0,1024),[1024,2048),[2048,3072),[3072,4096). Split s computes its own Half MMA result Cₛ. Only s=0 starts its accumulator from HalfMul(scale,residual); later splits start from zero. Adding the residual in all four splits would multiply that path by four. Adding it after all dots instead would change the existing Half accumulation sequence.

After independent computation, publish in order: P₀=C₀; P₁=HalfAdd(P₀,C₁); P₂=HalfAdd(P₁,C₂); final=HalfAdd(P₂,C₃). The output allocation itself holds P, and becomes the final tensor after split 3 writes its final Half result. This is not an arbitrary-order atomic sum and not one FP32 reduction. The structure reproduces the recorded publication boundaries.

03. Warp and thread ownership

Four M16 fragments and eight N8 fragments give one warp a 64×64 output. Represent it as four M16 groups × four N16 groups × four Half2 accumulator words per lane. Arrange four warps as two token halves and two channel halves to cover M128×N128. This keeps each output fragment in registers while reusing one A fragment across multiple N panels and one B fragment across four M panels. A CTA contains 128 threads, with lane=threadIdx.x and warp=threadIdx.y.

One instruction computes a 16-token × 8-output-channel tile with a reduction of 16 channels. All 32 lanes participate in the same matrix operation. Each lane supplies four 32-bit A words, two 32-bit B words, and two 32-bit C words. Each C word contains two Half accumulators, so a lane owns four output elements. A source loop over output groups or reduction panels repeats this operation; it does not launch a new warp.

The exact instruction on this path is mma.sync.aligned.m16n8k16.row.col.f16.f16.f16.f16. Both the accumulator input and output are Half. Do not replace its numerical contract with FP32 accumulation when constructing an exact oracle. For the FP8 path, packing to E4M3 is a distinct rounding step; for the FP16 path a packed word simply holds two Half values.

Let lane L run from 0 to 31, g = L // 4 and q = L % 4. The matrix coordinates below describe instruction operands after any kernel-specific loads and shuffles. Storage layouts are designed to supply these coordinates cheaply.

05. Execution and scheduling

Make the copy barrier part of the construction

Allocate 3 shared data slots and one 8-byte mbarrier per slot. Lane 0 of warp 0 initializes each barrier with 128 expected thread arrivals, then the CTA synchronizes before any producer can issue copies. On SM90+, IsCopyProducer elects one lane per participating warp; it issues an ordinary-address cp.async.bulk and registers the transferred byte count. On SM80/89, every lane issues 16-byte cp.async.cg stripes and attaches its own copies with cp.async.mbarrier.arrive. A 512-byte transfer needs one stripe per lane, a 1024-byte transfer needs two.

ArriveAndWait makes every thread arrive, obtains the current phase token, and polls until that exact phase completes. Reusing the same barrier address next iteration requires a new token; readiness from a previous cycle is insufficient. Completion also accounts for attached asynchronous transfers. Ordinary thread arrival alone cannot establish copy completion. The schedule must separately establish that the previous tile’s readers have finished before a slot is overwritten. No tensor-map descriptor, TMEM allocation, warp-group MMA or shared-to-register ldmatrix operation is used in this path: its shared vectors already have the correct MMA fragment order.

06. Trace one token through the source

Follow token 83 and, within it, Z[83,34]. Token 83 is group 5, row 3; it belongs to token CTA 0, warp 2, M16 fragment 1, lane 13’s first output row. Lane 13 also carries token 91 because the instruction’s output fragment has two row halves. We retain token 83 as the trace identity throughout: global packed input → shared operand stage → A/B registers → Half accumulator → ordered split partials → final output. Adjacent channels and lanes appear only when the collective instruction requires them.

A global allocation is device memory addressed by a pointer; loads can be served by hardware-managed L2 and, depending on the instruction, L1. A cache hit is not another program-visible tensor and the source does not guarantee cache residency. __ldca permits caching at all levels; __ldcg and PTX .cg select global-level caching that bypasses L1. An eviction or no_allocate hint is a performance policy, not a publication barrier.

Shared memory is an explicitly indexed block-local allocation. Another warp may read a producer's values only after the required block barrier or completed asynchronous-copy protocol. A warp shuffle exchanges register values among its active lanes; it does not address shared memory. Arrays named r_… express per-thread values, but only compiler output establishes whether they stay in physical registers or spill to local memory. Tensor-core accumulator fragments are also register operands. These kernels use mma.sync, not TMEM.

Define the packed layout before optimizing memory traffic

The public pointers address opaque packed buffers. A token group contains 16 rows. One native M16×K16 A panel consumes 512 bytes, distributed as 32 lanes ×16 bytes. For input width K and element size E, group g begins at g·16·K·E. A reduction step advances along K in whole panels. Within a panel, lane L reads the vector at L·16. The publication layout arranges token rows and channel pairs to make those four words immediately usable by MMA.

A packed B panel for 16 output channels also occupies 512 bytes. One lane’s uint4 supplies two N8 fragments: the first two words belong to the first N8, the next two words to the second. Across K panels, the record advances by N·32 bytes, where this kernel’s N is 1024. The equality follows from 16 reduction values × 2 bytes per value =32 bytes per output column. A cache-all vector load fetches those words directly to registers.

For FP16 weights, packed_f16_weight_index(k,n,N) returns a Half-element offset: panel=(k//16)·ceil(N/16)+n//16; lane=4·(n mod8)+floor((k mod8)/2); within-lane index=4·floor((n mod16)/8)+2·[k mod16≥8]+(k mod2). Multiply the result by two to obtain bytes. This gives you a scalar packer independent of the kernel’s vector-load formula.

Trace token 83 through the input and residual byte maps

Within one split, the reduction advances by K32, giving 32 steps. One 16-token group’s slab contains 32·16·2=1024 bytes. Its global base is U+(g·4096+s·1024+i·32)·16·2. The eight groups together occupy 8192 bytes per shared stage. This specialization copies 1024 bytes per producer operation, so 1 producer warp positions cooperate per group. In the source’s unified copy loop, copySlot=warp+4·Copy, group=firstGroup+floor(copySlot/1), and destination=stage·8192+copySlot·1024. Contraction coalesces the two K fragments in each 1024-byte group slab.

The consumer A vector is at shared (i mod3)·8192+floor(warp/2)·4·1024+lane·16+m·1024+kSubtile·512. W’s register vector starts at W+(s·1024+i·32)·1024·2+outputChannel·32+lane·16+kSubtile·32768+n16·512. There are 2 native K subtiles per step. The fixed 32768 stride is 1024 output columns ×32 bytes per native K panel; it is independent of the scalar element width.

For a Half partial, the address is partial+(g·1024+outputChannel)·32+lane·16+n16·512. The factor 32 is 16 tokens ×2 bytes. A residual vector instead uses the working element width: X+(g·1024+outputChannel)·16·2+lane·16+publicationPanel·512. Scale pairs are always Half, appended at W+4096·1024·2; within that tail, the byte offset is 2·(outputChannel+16·n16+8·n8+2·(lane mod4)). The example’s n16=2,n8=0,lane 13 therefore selects scale channels 34/35, beginning 68 bytes beyond the matrix.

Order split publication independently of computation

The source supports two protocols. With OrderedSplit=0, blockIdx.z is the logical split. A later split may compute its matrix partial while its predecessor runs, but before touching the predecessor’s global partial it polls the corresponding counter until the recorded split is available. The counter starts at −1, and each producer performs a release counter store after its publication and a CTA synchronization. This entry polls relaxed counters and uses a CTA barrier, but does not call the separate acquire helper in this source snapshot. The description records that protocol; it is not a new formal memory-order proof.

With OrderedSplit=s+1, the host launches only the XY plane for split s, with grid.z=1. The same stream completes that plane before entering the next split. The kernel skips the resident predecessor wait. The launcher selects this path when the complete dependent grid cannot fit its occupancy-derived capacity; otherwise waiting consumers could occupy resources needed by unscheduled producers. It preserves all 4 partials and their Half rounding rather than replacing them with a different reduction.

Reconstruct the full split and stage protocol

Verify the same token across partial and final boundaries

  1. Residual once: set W to zero. Valid output rows should equal the documented publication of HalfMul(scale,residual), with no factor of four and no contribution from other tokens.
  2. Each split contributes: place one nonzero input/weight pair in each K region and compare saved P₀,P₁,P₂ and final. They must follow the specified Half addition order. Values chosen near Half rounding boundaries distinguish this from a reassociated or FP32 sum.
  3. Scratch format: verify the output buffer holds valid Half partials before it becomes the final tensor; consumers must not read it early.
  4. Address ownership: use the worked token 83/channel 34 example and nearby lane/channel groups. Every output vector must be written once per publication phase, and guard bytes must remain unchanged.
  5. Schedule equivalence: run both admitted resident mode and forced ordered split mode on supported hardware; final bytes should agree. Include more XY blocks than fit in one wave to exercise the host’s capacity fallback.
  6. Tail and ring behavior: use legal token extents around group and CTA boundaries; exercise all 32 K steps so the 3 slots wrap repeatedly. Invalid groups must be zero during computation and omitted from output publication.

The optimization argument follows the construction: grouped MMA shares A across columns and B across tokens; the residual seed removes a separate pass; the staged A ring can overlap transfer with work; register B avoids a shared weight copy; split-specific epilogues avoid converting partials too early. Splitting also creates global scratch traffic and synchronization, and extra stages consume shared capacity. Those tradeoffs need measurements for this precision and geometry; this lesson reports no invented speedup.

108	for (int s_InitialStage = 0; s_InitialStage < Profile::s_InitialStages; ++s_InitialStage)
109		StageInput(s_InitialStage);
110	WaitStage(0);
111	FGlobalContractAccumulator r_Accumulator{};
112
113	// Only the first K split seeds the accumulator from the residual.
114	if (TileCoordinates.Split == 0)
115	{
116		// The record appends 1024 Half scales to the matrix. Lane's two adjacent
117		// channels share a packed scale; words 0/1 and 2/3 belong to separate N8s.
118		uint32_t r_ResidualScales[4][2];
119		#pragma unroll
120		for (int r_ChannelGroup = 0; r_ChannelGroup < 4; ++r_ChannelGroup)
121			#pragma unroll
122			for (int r_N8 = 0; r_N8 < 2; ++r_N8)
123				r_ResidualScales[r_ChannelGroup][r_N8] = *reinterpret_cast<const uint32_t*>(
124					Parameters.g_PackedWeights + Profile::MatrixBytes +
125					(TileCoordinates.g_OutputChannel + r_ChannelGroup * 16 + r_N8 * 8 +
126					 (TileCoordinates.Lane & 3) * 2) *
127						2);
128
129		#pragma unroll
130		for (int r_Spatial = 0; r_Spatial < 4; ++r_Spatial)
131		{
132			const int g_Group =
133				TileCoordinates.bBroadcastInput
134					? 0
135					: TileCoordinates.g_TokenGroupBase + (TileCoordinates.Warp >> 1) * 4 + r_Spatial;
136			const uint64_t g_ResidualTileBase =
137				Parameters.g_Residual +
138				uint64_t(g_Group * 1024 + TileCoordinates.g_OutputChannel) * 16 * Profile::ElementBytes +
139				TileCoordinates.Lane * 16;
140			{
141				#pragma unroll
142				for (int r_ChannelGroup = 0; r_ChannelGroup < 4; ++r_ChannelGroup)
143				{
144					const uint4 r_PackedResidual = g_Group < TileCoordinates.g_PaddedGroups
145													   ? __ldcg(reinterpret_cast<const uint4*>(
146															 g_ResidualTileBase + r_ChannelGroup * 512))
147													   : make_uint4(0, 0, 0, 0);
148					auto& r_AccumulatorWords = r_Accumulator.r_AccumulatorWords[r_Spatial][r_ChannelGroup];
149					r_AccumulatorWords[0] = HalfMul(r_PackedResidual.x, r_ResidualScales[r_ChannelGroup][0]);
150					r_AccumulatorWords[1] = HalfMul(r_PackedResidual.y, r_ResidualScales[r_ChannelGroup][0]);
151					r_AccumulatorWords[2] = HalfMul(r_PackedResidual.z, r_ResidualScales[r_ChannelGroup][1]);
152					r_AccumulatorWords[3] = HalfMul(r_PackedResidual.w, r_ResidualScales[r_ChannelGroup][1]);
153				}
154			}
155		}
156	}
157
158	// Native two-stage code peels the final MMA tile out of the prefetch loop.
159	// Keeping that drain explicit removes a per-iteration tail branch. The
160	// three-stage Half contraction retains its distinct refill lifecycle.
161	#pragma unroll 1
162	for (int ReductionTile = 0;
163		 ReductionTile < Profile::ReductionTiles - (Profile::s_InitialStages == 1 ? 1 : 0); ++ReductionTile)
164	{
165		ConsumeGlobalContractInputStage<Profile>(r_Accumulator, r_Weights, s_Storage, ReductionTile,
166												 TileCoordinates);
167		{
168			if (ReductionTile + 1 < Profile::ReductionTiles)
169			{
170				LoadWeights(ReductionTile + 1);
171				WaitStage(ReductionTile + 1);
172			}
173			if (ReductionTile + 3 < Profile::ReductionTiles)
174				StageInput(ReductionTile + 3);
175		}
176	}
177
178	{
179	}
180
181	// Compile-time split policy keeps the native branch outside all store loops.
182	const auto PublishFragments = [&](auto PublicationTag)
183	{
184		constexpr auto Publication = decltype(PublicationTag)::value;
185		const bool bFirstSplit = Publication == EGlobalContractSplitPublication::Runtime
186									 ? TileCoordinates.Split == 0
187									 : Publication == EGlobalContractSplitPublication::First;
188		const bool bIntermediateSplit = Publication == EGlobalContractSplitPublication::Runtime
189											? TileCoordinates.Split < 3
190											: Publication == EGlobalContractSplitPublication::Intermediate;
191
192		// Serial publication preserves the DLL's Half rounding between K splits.
193		// FP8 keeps partial sums in a separate Half buffer until the fourth split.
194		const uint64_t g_PartialSums = bFp8 ? Parameters.g_SplitAccumulator : Parameters.g_Output;
195		#pragma unroll
196		for (int r_Spatial = 0; r_Spatial < 4; ++r_Spatial)
197		{
198			const int g_Group =
199				TileCoordinates.g_TokenGroupBase + (TileCoordinates.Warp >> 1) * 4 + r_Spatial;
200			if (g_Group < TileCoordinates.g_PaddedGroups)
201			{
202				const uint64_t g_HalfBase = g_PartialSums +
203											uint64_t(g_Group * 1024 + TileCoordinates.g_OutputChannel) * 32 +
204											TileCoordinates.Lane * 16;
205				#pragma unroll
206				for (int r_ChannelGroup = 0; r_ChannelGroup < 4; ++r_ChannelGroup)
207				{
208					auto& r_AccumulatorWords = r_Accumulator.r_AccumulatorWords[r_Spatial][r_ChannelGroup];
209					const uint64_t g_PartialSumAddress = g_HalfBase + r_ChannelGroup * 512;
210					if (bFirstSplit)
211						StoreNoAllocate(g_PartialSumAddress,
212										make_uint4(r_AccumulatorWords[0], r_AccumulatorWords[1],
213												   r_AccumulatorWords[2], r_AccumulatorWords[3]));
214					else if (bIntermediateSplit)
215						ReduceHalf4(g_PartialSumAddress,
216									make_uint4(r_AccumulatorWords[0], r_AccumulatorWords[1],
217											   r_AccumulatorWords[2], r_AccumulatorWords[3]));
218					else
219					{
220						const uint4 r_PreviousSplitWords =
221							__ldca(reinterpret_cast<const uint4*>(g_PartialSumAddress));
222						r_AccumulatorWords[0] = HalfAdd(r_PreviousSplitWords.x, r_AccumulatorWords[0]);
223						r_AccumulatorWords[1] = HalfAdd(r_PreviousSplitWords.y, r_AccumulatorWords[1]);
224						r_AccumulatorWords[2] = HalfAdd(r_PreviousSplitWords.z, r_AccumulatorWords[2]);
225						r_AccumulatorWords[3] = HalfAdd(r_PreviousSplitWords.w, r_AccumulatorWords[3]);
226						StoreNoAllocate(g_PartialSumAddress,
227										make_uint4(r_AccumulatorWords[0], r_AccumulatorWords[1],
228												   r_AccumulatorWords[2], r_AccumulatorWords[3]));
229					}
230				}
231				{
232				}
233			}
234		}
235	};
236
237	const uint64_t g_SplitCounters =
238		Parameters.g_SplitCounters + (TileCoordinates.g_TokenGroupBase + TileCoordinates.g_ChannelBlock) * 4;
239	if (TileCoordinates.Split > 0)
240	{
241		// The stream boundary orders Half scratch updates without resident peers.
242		if (Parameters.OrderedSplit == 0 && TileCoordinates.Lane == 0 && TileCoordinates.Warp == 0)
243			while (int32_t(CounterLoadRelaxed(g_SplitCounters)) < TileCoordinates.Split - 1)
244				PollSleep(64);
245		__syncthreads();
246	}
247
248	PublishFragments(
249		std::integral_constant<EGlobalContractSplitPublication, EGlobalContractSplitPublication::Runtime>{});
250	__syncthreads();
251	if (TileCoordinates.Lane == 0 && TileCoordinates.Warp == 0)
252		CounterStoreRelease(g_SplitCounters, TileCoordinates.Split);
253#endif
254}
